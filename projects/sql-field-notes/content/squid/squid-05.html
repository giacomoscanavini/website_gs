SQL Squid Game / Level 5

Count a player’s closest interactions

Normalize both sides of an interaction before counting counterpart players.

Task

For the Marbles game, the Front Man needs you to discover who Player 456's closest companion is. First, find the player who has interacted with Player 456 the most frequently in daily activities. Then, confirm this player is still alive and return a row with both players' first names, and the number of interactions they've had.

My SQL 
WITH
	Player_interactions AS (
	  SELECT t.target_id, t.player_id, COUNT(*) AS counts
	  FROM (
		  SELECT 
			  456 AS target_id,
			  CASE
				WHEN player1_id <> 456 THEN player1_id
				ELSE player2_id 
			  END AS player_id,
			  type,
			  EXTRACT(DAY FROM date) AS day,
			  EXTRACT(MONTH FROM date) AS month,
			  EXTRACT(YEAR FROM date) AS year
		  FROM Daily_interactions
		  WHERE player1_id = 456 OR player2_id = 456
	  ) AS t
	  GROUP BY t.target_id, t.player_id
	  ORDER BY counts DESC
	)
	
SELECT 
	pl.first_name AS name_456,
	p.first_name AS name_other,
	counts
FROM Player_interactions i
INNER JOIN player pl
	ON i.target_id = pl.id
INNER JOIN player p
	ON i.player_id = p.id
WHERE p.status = 'alive'
LIMIT 1
pandas alternative 
import pandas as pd

mask = daily_interactions['player1_id'].eq(456) | daily_interactions['player2_id'].eq(456)
interactions = daily_interactions.loc[mask].copy()
interactions['player_id'] = interactions['player1_id'].where(
    interactions['player1_id'].ne(456), interactions['player2_id'])
counts = interactions.groupby('player_id', as_index=False).size().rename(columns={'size': 'counts'})
counts['target_id'] = 456
target = player[['id', 'first_name']].rename(columns={'id': 'target_id', 'first_name': 'name_456'})
other = player[['id', 'first_name', 'status']].rename(columns={'id': 'player_id', 'first_name': 'name_other'})
joined = counts.merge(target, on='target_id').merge(other, on='player_id')
# Explicit final sort is an authored addition
result = (joined.loc[joined['status'].eq('alive')]
          .sort_values('counts', ascending=False).head(1)
          [['name_456', 'name_other', 'counts']])

Added translation · DataFrame assumptions

How it works

Each interaction involving Player 456 is converted to a counterpart ID regardless of which player column contains 456. Counts are grouped by counterpart, joined to both names, and filtered to living counterparts before LIMIT 1.

Source-aware note. The brief says to find the most frequent counterpart and then confirm they are alive; the saved query filters living counterparts before taking one row. It also sorts only inside the CTE, without an outer ORDER BY. The pandas translation below explicitly sorts at the final selection to express the frequency intent; that final sort is an authored addition, not an original SQL line.

No query-result table was stored in this SQL file. Sample-schema rows below are inputs, not the answer.
