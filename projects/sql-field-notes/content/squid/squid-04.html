SQL Squid Game / Level 4

Rank ten-player teams

Filter groups by size, label their average age and rank the retained teams.

Task

The Front Man needs to analyze and rank the teams before the Tug of War game begins. For each team that has exactly 10 players, calculate their average player age. Additionally, categorize the teams based on their average player age into three age groups: 'Fit': Average age < 40 'Grizzled': Average age between 40 and 50 (inclusive) 'Elderly': Average age > 50 Show the team_id, average age, age group, and rank the teams based on their average player age (highest average age = rank 1).

SQL 
SELECT 
    t.team_id, 
    t.age_team,
    CASE
        WHEN t.age_team < 40 THEN 'Fit'
        WHEN t.age_team > 50 THEN 'Elderly'
        ELSE 'Grizzled'
    END AS age_group,
    RANK() OVER (ORDER BY age_team DESC) AS rank
FROM (
    SELECT team_id, COUNT(*) AS n_players, AVG(age) AS age_team
    FROM player  
    GROUP BY team_id
) t
WHERE t.n_players = 10
pandas 
import pandas as pd

teams = player.groupby('team_id', as_index=False, dropna=False).agg(
    n_players=('id', 'size'), age_team=('age', 'mean'))
result = teams.loc[teams['n_players'].eq(10), ['team_id', 'age_team']].copy()
result['age_group'] = 'Grizzled'
result.loc[result['age_team'].lt(40), 'age_group'] = 'Fit'
result.loc[result['age_team'].gt(50), 'age_group'] = 'Elderly'
result['rank'] = result['age_team'].rank(method='min', ascending=False).astype('Int64')

pandas · DataFrame assumptions

How it works

The inner query counts members and averages age by team. The outer query keeps teams of exactly ten, assigns the Fit, Grizzled or Elderly label, and ranks higher average ages first.

Ranks and boundaries. RANK gives tied ages the same rank and leaves gaps afterward. Ages 40 and 50 fall in Grizzled. The query does not filter player status or specify a final output order.

No result table is recorded. The schema examples below are input rows.
