SQL Squid Game / Level 3

Compare hot and cold months

Select temperature extremes, join by month and aggregate completion times.

Task

Analyze the average completion times for each shape in the honeycomb game during the hottest and coldest months, using data from the past 20 years only. Order the results by average completion time.

SQL 
WITH 
    Extrama_month AS (
        SELECT *
        FROM (
            SELECT * 
            FROM monthly_temperatures
            ORDER BY avg_temperature ASC
            LIMIT 1
        ) as Cold

        UNION

        SELECT *
        FROM (
            SELECT * 
            FROM monthly_temperatures
            ORDER BY avg_temperature DESC
            LIMIT 1
        ) as Hot
    ),

    Honeycomb_game_extended AS (
        SELECT 
            shape, 
            average_completion_time,
            EXTRACT(MONTH FROM date) AS month_num,
            EXTRACT(YEAR FROM date) AS year_num
        FROM honeycomb_game
    )

SELECT 
    h.shape, 
    h.month_num,
    AVG(h.average_completion_time) AS avg_temp
FROM Honeycomb_game_extended h 
INNER JOIN Extrama_month e
    ON e.month = h.month_num
WHERE h.year_num >= 2006
GROUP BY h.shape, h.month_num
ORDER BY avg_temp ASC
pandas 
import pandas as pd

cold = monthly_temperatures.sort_values('avg_temperature').head(1)
hot = monthly_temperatures.sort_values('avg_temperature', ascending=False).head(1)
extreme = pd.concat([cold, hot], ignore_index=True).drop_duplicates()
games = honeycomb_game.copy()
dates = pd.to_datetime(games['date'])
games['month_num'], games['year_num'] = dates.dt.month, dates.dt.year
joined = games.merge(extreme[['month']], left_on='month_num', right_on='month')
result = (joined.loc[joined['year_num'].ge(2006)]
          .groupby(['shape', 'month_num'], as_index=False)
          .agg(avg_temp=('average_completion_time', 'mean'))
          .sort_values('avg_temp'))

pandas · DataFrame assumptions

How it works

Extrama_month selects one coldest and one hottest monthly-temperature row. A second CTE extracts the month and year from each game date. The final query averages completion time by shape and selected month, then sorts the averages.

Dates and units. year >= 2006 is a fixed cutoff, not a moving twenty-year window. The avg_temp alias represents average completion time. Tied hottest or coldest months have no secondary ordering.

No result table is recorded. The schema examples below are input rows.
