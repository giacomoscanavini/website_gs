SQL Squid Game

Nine SQL challenges covering filters, aggregates, joins, ranking, and time comparisons, with pandas implementations.

Levels

01 Filter the player pool 02 Calculate the ration threshold 03 Compare hot and cold months 04 Rank ten-player teams 05 Count a player’s closest interactions 06 Trace equipment to its first failure 07 Join room checks and camera sightings 08 Find the longest hesitation 09 Reconstruct access-log overlaps
DataFrame assumptions. Each SQL table has an in-memory DataFrame with the same columns and a snake_case variable name. Keys are non-null, dimension keys are unique, and date/time values are parseable. Differences in sorting, filtering, or tie handling are stated beside the relevant solution.

Data and results

Each level includes its task and sample schema. Sample rows illustrate the input tables; they are not a full database or query result. No result tables are recorded for these solutions.

Implementation limits. Level 3 uses a fixed 2006 cutoff. Level 5 sorts inside a CTE rather than at final selection. Level 9 uses same-day time comparisons and does not exclude the suspect. The relevant pages explain how these choices affect the results.
