SQL Squid Game / Level 6

Trace equipment to its first failure

Narrow by game and supplier before calculating an equipment-level lifetime.

Task

The guards are investigating equipment durability across different game types, as some equipment has been breaking prematurely. Determine the game type with the highest number of equipment failures and identify the supplier responsible for the most failures within that game type. Finally, calculate the average lifespan until first failure, in whole years (using 365.2425 days per year), of all failed equipment supplied by this supplier for the most faulty game type.

My SQL 
WITH	
	Game_with_highest_failures AS (
	  	SELECT e.game_type
		FROM Equipment e
		INNER JOIN Failure_incidents f
			ON e.id = f.failed_equipment_id
		GROUP BY e.game_type
		ORDER BY COUNT(*) DESC
		LIMIT 1
	),
	Worst_supplier AS (
		SELECT e.supplier_id
		FROM Equipment e
		INNER JOIN Game_with_highest_failures g
			ON e.game_type = g.game_type
		INNER JOIN Failure_incidents f
			ON e.id = f.failed_equipment_id
		GROUP BY e.supplier_id
		ORDER BY COUNT(*) DESC
		LIMIT 1
	),
	Installation_records AS (
	  SELECT e.id, e.installation_date 
	  FROM Equipment e, Worst_supplier w, Game_with_highest_failures g
	  WHERE e.game_type = g.game_type AND e.supplier_id = w.supplier_id
	),
	Failed_time AS (
	  SELECT 
		  f.failed_equipment_id,
		  MIN(i.installation_date) AS installation_date,
		  MIN(f.failure_date) AS first_failure_date,
		  (MIN(f.failure_date) - MIN(i.installation_date)) / 365.2425 AS time_to_first_failure
	  FROM Failure_incidents f
	  INNER JOIN Installation_records i
		  ON f.failed_equipment_id = i.id
	  GROUP BY f.failed_equipment_id
	)
		   
SELECT FLOOR(AVG(time_to_first_failure))
FROM Failed_time
pandas alternative 
import pandas as pd
import numpy as np

joined = equipment.merge(failure_incidents, left_on='id', right_on='failed_equipment_id',
                         suffixes=('_equipment', '_incident'))
result = pd.DataFrame({'average_lifespan_years': [None]})
if not joined.empty:
    game_counts = joined.groupby('game_type', dropna=False).size()
    game_type = game_counts.sort_values(ascending=False).index[0]
    in_game = joined.loc[joined['game_type'].eq(game_type)]
    supplier_id = in_game.groupby('supplier_id').size().sort_values(ascending=False).index[0]
    failures = in_game.loc[in_game['supplier_id'].eq(supplier_id)].copy()
    failures['installation_date'] = pd.to_datetime(failures['installation_date'])
    failures['failure_date'] = pd.to_datetime(failures['failure_date'])
    first = failures.groupby('failed_equipment_id').agg(
        installed=('installation_date', 'min'), failed=('failure_date', 'min'))
    years = (first['failed'] - first['installed']).dt.total_seconds() / (86400 * 365.2425)
    result = pd.DataFrame({'average_lifespan_years': [np.floor(years.mean())]})

Added translation · DataFrame assumptions

How it works

First count failure incidents by game type. Within the selected game type, count incidents by supplier. Restrict installation records to that pair, find each failed item’s first failure, and floor the average lifetime after dividing days by 365.2425.

Source-aware note. The two rankings count incident rows, not distinct pieces of equipment; the final mean gives each failed item one lifetime. FLOOR is applied after averaging. The SQL assumes date subtraction yields days. The pandas translation makes that assumption explicit with total_seconds / 86400. No tie-breaker is defined for the top game or supplier.
