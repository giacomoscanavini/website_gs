SQL Squid Game / Level 2

Calculate the ration threshold

Count eligible players, round down a proportion and compare it with supply.

Task

The organizers need to calculate how many food portions to withhold to create the right amount of tension. In a table, calculate how many rations would feed 90% of the remaining(alive) non-insider players (rounded down), and in another column, indicate if the current rations supply is sufficient. (True or False)

My SQL 
WITH
    table_prop AS (
        SELECT FLOOR( COUNT(*) * 0.9 ) AS portions
        FROM player
        WHERE status = 'alive' AND isinsider = false
    )

SELECT 
    table_prop.portions AS portions,
    CASE 
        WHEN table_prop.portions > rations.amount THEN 'False'
        ELSE 'True'
    END AS amount
FROM table_prop, rations
pandas alternative 
import pandas as pd

eligible = player['status'].eq('alive') & player['isinsider'].eq(False)
portions = int(eligible.fillna(False).sum()) * 9 // 10
result = rations[['amount']].copy()
result['portions'] = portions
insufficient = result['amount'].lt(portions).fillna(False)
result['amount'] = insufficient.map({True: 'False', False: 'True'})
result = result[['portions', 'amount']]

How it works

The CTE counts living non-insiders and rounds 90% of that count down. The outer SELECT compares that single count with each row in rations and produces portions plus the source’s amount label.

Source-aware note. The source emits the strings 'True' and 'False', not a Boolean type, and calls the second column amount. Those choices are preserved. If rations has several rows, the cross join returns several comparisons rather than summing supply.
