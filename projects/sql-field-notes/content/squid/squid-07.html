SQL Squid Game / Level 7

Join room checks and camera sightings

Build a guard report with per-sighting gaps and a shared detection range.

Task

Create a comprehensive report identifying guards who were missing from their sleeping quarters during off-duty hours. This report should include the following details for each missing guard, ordered by guard ID: Guard Number Code Name Status Last Seen in Room Spotted Outside Room Time Spotted Outside Room >Location Time Between Room and Outside Time Range from First to Last Detection of Any Guard

SQL 
SELECT 
	g.id AS guard_number,
	g.code_name AS code_name, 
	g.status,  
	r.last_check_time AS last_seen_in_room,
	c.movement_detected_time AS spotted_outside_room_time,
	c.location AS spotted_outside_room_location,
	c.movement_detected_time - r.last_check_time AS time_between_room_and_outside,
	(SELECT MAX(Camera.movement_detected_time) - MIN(Camera.movement_detected_time)
     FROM Camera
     WHERE Camera.guard_spotted_id IS NOT NULL) AS time_range_first_last_detection
FROM Guard g
LEFT JOIN Room r
	ON r.id = g.assigned_room_id
INNER JOIN Camera c
	ON c.guard_spotted_id = g.id
WHERE r.isVacant = true
ORDER BY g.id
pandas 
import pandas as pd

guards = guard.rename(columns={'id': 'guard_number'})
rooms = room.rename(columns={'id': 'room_id', 'last_check_time': 'last_seen_in_room'})
cameras = camera.rename(columns={'id': 'camera_id',
                                 'movement_detected_time': 'spotted_outside_room_time',
                                 'location': 'spotted_outside_room_location'})
joined = guards.merge(rooms, how='left', left_on='assigned_room_id', right_on='room_id')
joined = joined.merge(cameras.loc[cameras['guard_spotted_id'].notna()],
                      left_on='guard_number', right_on='guard_spotted_id')
joined = joined.loc[joined['isvacant'].eq(True)].copy()
seen = pd.to_timedelta(joined['spotted_outside_room_time'].astype('string'))
checked = pd.to_timedelta(joined['last_seen_in_room'].astype('string'))
joined['time_between_room_and_outside'] = seen - checked
times = pd.to_timedelta(camera.loc[camera['guard_spotted_id'].notna(),
                                    'movement_detected_time'].astype('string'))
joined['time_range_first_last_detection'] = times.max() - times.min()
result = joined.sort_values('guard_number')[[
    'guard_number', 'code_name', 'status', 'last_seen_in_room',
    'spotted_outside_room_time', 'spotted_outside_room_location',
    'time_between_room_and_outside', 'time_range_first_last_detection']]

How it works

Join guards to their rooms and camera sightings, retain vacant rooms, and compute sighting time minus last room check. A scalar subquery repeats the range between the earliest and latest camera detections with a non-null guard ID on every output row.

Join scope. Each camera match can produce a separate row for a guard. The query does not apply a shift schedule, movement_detected condition, or explicit after-room-check filter. Time subtraction assumes one day. The Camera sample table is mislabeled failure_incidents in the archived schema comments.

No result table is recorded. The schema examples below are input rows.
