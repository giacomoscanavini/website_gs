Translate the operation, not just the syntax

SQL and pandas expressions are equivalent only when they return the same rows and columns, with the same treatment of missing values, duplicates, and ordering. Compare the operation’s behavior, not just its syntax.

SQL pandas pattern Watch for
SELECT a, b df[['a', 'b']] A list preserves a DataFrame; projection does not deduplicate.
WHERE a > 3 AND b = 1 df.loc[df['a'].gt(3) & df['b'].eq(1)] Use elementwise & / |, not Python and / or.
IS NULL / IS NOT NULL s.isna() / s.notna() Never test SQL NULL using = NULL.
IN ('A','B') s.isin(['A','B']) NOT IN and missing values require explicit care.
SELECT DISTINCT a df[['a']].drop_duplicates() Deduplicate only the columns that form the result.
ORDER BY a DESC, b df.sort_values(['a','b'], ascending=[False,True]) Add a unique tie-break when a single deterministic row is required.
LIMIT 5 OFFSET 10 sorted_df.iloc[10:15] Sort before selecting a page.
INNER / LEFT JOIN left.merge(right, on='id', how='inner'/'left') Validate expected one-to-one or many-to-one cardinality.
COUNT(*) / COUNT(x) groupby.size() / groupby[x].count() size counts rows; count ignores missing x.
COUNT(DISTINCT x) groupby['x'].nunique() Distinct nonmissing values.
SUM(x) groupby['x'].sum(min_count=1) Use min_count=1 when an all-missing group must stay missing.
GROUP BY k df.groupby('k', dropna=False) SQL retains a NULL grouping key; default pandas groupby drops it.
HAVING SUM(x) > 0 Aggregate, then filter the aggregated frame. Do not confuse this with a pre-aggregation WHERE.
MIN(x) OVER (PARTITION BY k) df.groupby('k')['x'].transform('min') transform broadcasts the statistic to every source row.
DENSE_RANK() OVER (...) groupby['x'].rank(method='dense', ascending=False) Use the ranking method that preserves the intended ties.
LAG / LEAD with ORDER BY Sort, then groupby.shift(1) / shift(-1). A previous row is not necessarily the previous calendar day.
SUM(x) OVER (ORDER BY t ROWS ...) Sort, then cumsum(). A cumulative total differs from a grouped total.
UNION ALL / UNION concat(...) / concat(...).drop_duplicates() Align selected columns; SQL uses positions and pandas uses names.
CASE WHEN condition ... Boolean masks with where/map. Keep NULL behavior and labels explicit.
UPDATE / DELETE Assign with .loc / retain the complement mask. A DataFrame change does not update the database.

A tiny aggregation example

pandas 
visits = pd.DataFrame({'shop': ['A', 'A', 'B'], 'amount': [10, 20, None]})
result = visits.groupby('shop', dropna=False)['amount'].sum(min_count=1).reset_index()

Result: shop A has 30; shop B remains missing. Without min_count=1, the all-missing B group would become zero, unlike SQL SUM.

Three important non-equivalences

Missing merge keys: pandas can match missing keys to each other; SQL equality joins do not. Group keys: SQL groups NULL keys together, while pandas needs dropna=False to retain them. Logical complements: NOT(condition) in SQL can still be unknown for a NULL row, whereas a pandas negation may include it depending on dtype and expression.
