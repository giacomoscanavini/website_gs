Setup and conventions

One problem at a time

Every exercise has its own tables. SQLBolt examples use its tutorial schema; the Leetcode SQL targets MySQL 8 or later. Do not combine unrelated examples into one database script.

pandas

The function examples accept DataFrames with the same column names as the exercise tables. Each practice implementation includes its imports. SQLBolt snippets assume import pandas as pd and lowercase DataFrame names matching their tables.

Create the input DataFrames from the exercise data before calling a function. Date operations require datetime-like columns; use pd.to_datetime when loading dates as strings.

Dates and order

A previous row is not necessarily the previous calendar day. Sort before shifting or rolling, and use calendar-date comparisons when the task asks for days. A half-open month interval includes the start date and excludes the first day of the following month.

Rounding

Python and pandas normally round exact halfway values to the nearest even result. MySQL exact-value rounding uses halves away from zero. Where needed, the examples include this half-up helper.

pandas 
"""Authored pandas study alternatives; see the corresponding pages for assumptions.
Requires pandas. All functions return a new result except delete_duplicate_emails,
which intentionally mutates its input. Synthetic tests are in ../tests/.
"""
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd


def round_half_up(value, digits: int = 2):
    """Round the decimal representation of value; preserve missing values.

    This does not recover precision already lost in binary floating-point arithmetic.
    For exact financial arithmetic, retain Decimal or integer minor units upstream.
    """
    if pd.isna(value):
        return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

The helper rounds the decimal representation of its input. It does not undo floating-point precision loss; retain Decimal values or integer minor units when exact decimal arithmetic is required.
