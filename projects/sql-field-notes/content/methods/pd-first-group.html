First row per group

Earliest row

Quick syntax

pandas 
df.sort_values('date').groupby('id').first()
Implementation note. The image labels this “first row”, but groupby.first() takes the first non-missing value in each column by default. With missing data, those values can come from different rows. Sort and use groupby.head(1) when you need an intact row. Documentation ↗
