DATEDIFF()

Difference in days

Quick syntax

MySQL 
DATEDIFF(d1,d2)
Implementation note. DATEDIFF(d1,d2) is d1 minus d2 using date parts. TIMESTAMPDIFF(unit,d1,d2) uses d2 minus d1. Documentation ↗
