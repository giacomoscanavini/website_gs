Inspect December event check-ins

Look up the recorded candidates’ event attendance during December 2017.

SQL 
-- Need to find who attended the SQL symphony city concerts
SELECT 
	p.id, p.name, 
	f.event_name, f.date
FROM Facebook_event_checkin f
LEFT JOIN Person p ON f.person_id = p.id
WHERE 
	f.person_id IN (78881, 90700, 99716)
	AND (f.date > 20171130 AND f.date < 20180101)

How it works

The query selects events for the three saved candidate IDs within December 2017. The result table shows three SQL Symphony Concert check-ins for one candidate.

Query scope. The query filters candidate IDs and December dates, but not the event name or attendance count. Three concert visits are visible in the result table; GROUP BY and HAVING do not enforce that condition here.
