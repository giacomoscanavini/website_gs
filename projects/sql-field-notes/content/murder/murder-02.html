SQL Murder City / Step 2

Find the two witnesses

Combine an ordered address search with a name-and-street filter.

SQL 
-- Find more information about the witnesses (note that ORDER BY and LIMIT would have been applied to the same SELECT statement as UNION so we have to separate them)
SELECT * 
FROM (
  	SELECT * 
  	FROM Person
	WHERE address_street_name = 'Northwestern Dr'
	ORDER BY address_number DESC
	LIMIT 1
)

UNION 

SELECT * 
FROM Person 
WHERE 
	address_street_name = 'Franklin Ave'
	AND name LIKE 'Annabel%'
pandas 
import pandas as pd

first = (person.loc[person['address_street_name'].eq('Northwestern Dr')]
         .sort_values('address_number', ascending=False).head(1))
second = person.loc[
    person['address_street_name'].eq('Franklin Ave')
    & person['name'].str.startswith('Annabel', na=False)
]
result = pd.concat([first, second], ignore_index=True).drop_duplicates()

How it works

The first branch takes the highest address_number on Northwestern Dr. The second finds names beginning with Annabel on Franklin Ave. Wrapping the first branch makes its ORDER BY and LIMIT local to that branch; UNION combines the two result sets.

Duplicate handling. pandas uses concat followed by drop_duplicates to match UNION rather than UNION ALL. The final SQL UNION does not specify row order.
