SQL Murder City / Step 3

Read the witness interviews

Attach each witness’s name to the interview transcript.

My SQL 
-- Have these people been interviewed? If so, what have they reported?
SELECT 
	p.id,
	p.name,
	i.transcript
FROM Interview i
LEFT JOIN Person p ON i.person_id = p.id
WHERE p.id = 14887 OR p.id = 16371
pandas alternative 
import pandas as pd

joined = interview.merge(person[['id', 'name']], how='left',
                         left_on='person_id', right_on='id')
result = joined.loc[joined['id'].isin([14887, 16371]),
                    ['id', 'name', 'transcript']].copy()

How it works

The saved query joins Interview to Person, then selects the two witness IDs recorded in the preceding table. Together, the transcripts contribute a gym membership prefix, a gold membership, a partial licence plate and a gym visit date.

Source-aware note. The filter on Person IDs removes unmatched person rows after the LEFT JOIN. The translation retains the same join direction and filter, assuming the Person primary key is unique.
