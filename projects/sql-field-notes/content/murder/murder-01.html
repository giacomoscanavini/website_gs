SQL Murder City / Step 1

Retrieve the crime report

Start with the date, city and type of crime to recover the missing report.

SQL 
-- Find more information regarding the murder by reading the crime report
SELECT * 
FROM Crime_scene_report
WHERE 
    type = 'murder' 
    AND city = 'SQL City' 
    AND date = '20180115'
pandas 
import pandas as pd

mask = (crime_scene_report['type'].eq('murder')
        & crime_scene_report['city'].eq('SQL City')
        & crime_scene_report['date'].astype('string').eq('20180115'))
result = crime_scene_report.loc[mask].copy()

How it works

Three conditions narrow Crime_scene_report to the murder in SQL City on 15 January 2018. The recorded report supplies two different routes to the witnesses: a street’s highest house number and a name prefix on another street.

Date format. Dates use YYYYMMDD values rather than SQL DATE literals. The pandas implementation converts them to strings so it can compare either integer or string input values.
