INNER JOIN

An INNER JOIN returns matching rows from both tables. Join movies.id to boxoffice.movie_id; qualify columns with aliases to make their origins clear.

Note. The tutorial specifies one BoxOffice record per movie. The pandas validate argument checks that assumption; a many-to-many join would multiply rows.

01 · Domestic and international sales per movie

SQL 
SELECT m.title, b.domestic_sales, b.international_sales
FROM movies m JOIN boxoffice b ON m.id = b.movie_id;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
result = m[['title', 'domestic_sales', 'international_sales']]

02 · Movies with higher international sales

SQL 
SELECT m.title, b.domestic_sales, b.international_sales
FROM movies m JOIN boxoffice b ON m.id = b.movie_id
WHERE b.international_sales > b.domestic_sales;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
result = m.loc[m['international_sales'].gt(m['domestic_sales']), ['title', 'domestic_sales', 'international_sales']]

03 · Movies ordered by rating, highest first

SQL 
SELECT m.title, b.rating FROM movies m
JOIN boxoffice b ON m.id = b.movie_id ORDER BY b.rating DESC;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
result = m.sort_values('rating', ascending=False)[['title', 'rating']]
