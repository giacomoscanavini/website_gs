SQLBolt / Lesson 17

ALTER TABLE

ALTER TABLE changes an existing schema. The exercises add two columns, one with a default. The lesson also discusses dropping columns and renaming tables.

Note. The lesson describes limitations of its embedded engine; do not treat that as a universal statement about current SQLite. In pandas, assigning English fills existing rows but does not establish a default for future rows.

01 · Add floating-point aspect ratio

SQL 
ALTER TABLE movies ADD COLUMN Aspect_ratio FLOAT;
pandas 
movies['aspect_ratio'] = pd.Series(pd.NA, index=movies.index, dtype='Float64')

02 · Add language with English default

SQL 
ALTER TABLE movies ADD COLUMN Language TEXT DEFAULT 'English';
pandas 
movies['language'] = 'English'
