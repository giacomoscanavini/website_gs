Logical query order

The lesson’s logical order is FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT/OFFSET. This explains which values and aliases are available to each clause.

Note. This is a logical model, not a promise of the physical execution plan. Optimizers may transform execution. Window functions add another logical stage, covered in the reference pages.

01 · Film count per director

SQL 
SELECT director, COUNT(*) AS movie_count FROM movies GROUP BY director;
pandas 
result = movies.groupby('director', dropna=False).size().reset_index(name='movie_count')

02 · Combined domestic and international revenue per director

SQL 
SELECT m.director, SUM(b.domestic_sales + b.international_sales) AS total_sales
FROM movies m JOIN boxoffice b ON m.id = b.movie_id GROUP BY m.director;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
m = m.assign(total_sales=m['domestic_sales'] + m['international_sales'])
result = m.groupby('director', dropna=False)['total_sales'].sum(min_count=1).reset_index()
