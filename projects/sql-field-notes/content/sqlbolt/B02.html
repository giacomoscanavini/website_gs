SQLBolt / Lesson 2

Numeric constraints

WHERE filters rows before projection or aggregation. BETWEEN includes both endpoints; IN tests membership. Combine conditions with AND or OR.

Note. The first-five exercise uses the tutorial’s sequential IDs, not an assumption that arbitrary database IDs always encode release order.

01 · Movie whose ID is 6

SQL 
SELECT * FROM movies WHERE id = 6;
pandas 
result = movies.loc[movies['id'].eq(6)].copy()

02 · Releases from 2000 through 2010

SQL 
SELECT * FROM movies WHERE year BETWEEN 2000 AND 2010;
pandas 
result = movies.loc[movies['year'].between(2000, 2010)].copy()

03 · Releases outside that interval

SQL 
SELECT * FROM movies WHERE year NOT BETWEEN 2000 AND 2010;
pandas 
result = movies.loc[movies['year'].notna() & ~movies['year'].between(2000, 2010)].copy()

04 · First five movies, with release year

SQL 
SELECT title, year FROM movies WHERE id BETWEEN 1 AND 5;
pandas 
result = movies.loc[movies['id'].between(1, 5), ['title', 'year']].copy()
