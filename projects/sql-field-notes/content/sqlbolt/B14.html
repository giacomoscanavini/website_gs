SQLBolt / Lesson 14

UPDATE rows

UPDATE changes the columns named in SET for rows matching WHERE. Omit WHERE only when changing every row is intentional.

Note. Preview the same WHERE predicate with SELECT before changing stored data. Pandas .loc assignment changes a DataFrame in memory, not its source database.

01 · Correct A Bug’s Life director

SQL 
UPDATE movies SET director = 'John Lasseter' WHERE title = 'A Bug''s Life';
pandas 
movies.loc[movies['title'].eq("A Bug's Life"), 'director'] = 'John Lasseter'

02 · Correct Toy Story 2 release year

SQL 
UPDATE movies SET year = 1999 WHERE title = 'Toy Story 2';
pandas 
movies.loc[movies['title'].eq('Toy Story 2'), 'year'] = 1999

03 · Correct Toy Story 8 title and director

SQL 
UPDATE movies SET title = 'Toy Story 3', director = 'Lee Unkrich' WHERE title = 'Toy Story 8';
pandas 
movies.loc[movies['title'].eq('Toy Story 8'), ['title', 'director']] = ['Toy Story 3', 'Lee Unkrich']
