Aggregates and GROUP BY

Aggregates collapse rows into summary values. Without GROUP BY the entire input is one group; with GROUP BY there is one result per group. COUNT(*) counts rows, whereas COUNT(column) excludes NULL.

Note. Pandas groupby drops missing group keys unless dropna=False. SUM in SQL returns NULL when no non-NULL values contribute; sum(min_count=1) preserves that distinction.

01 · Longest employee tenure

SQL 
SELECT MAX(years_employed) AS max_years FROM employees;
pandas 
result = pd.DataFrame({'max_years': [employees['years_employed'].max()]})

02 · Mean tenure per role

SQL 
SELECT role, AVG(years_employed) AS average_years FROM employees GROUP BY role;
pandas 
result = employees.groupby('role', dropna=False, as_index=False).agg(average_years=('years_employed', 'mean'))

03 · Total employee-years per building

SQL 
SELECT building, SUM(years_employed) AS total_years FROM employees GROUP BY building;
pandas 
result = employees.groupby('building', dropna=False)['years_employed'].sum(min_count=1).reset_index(name='total_years')

Sum years_employed; counting employees answers a different question. A building with nobody assigned is absent unless buildings is left-joined first.
