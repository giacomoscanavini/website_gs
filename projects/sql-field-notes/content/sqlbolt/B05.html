Review · Simple SELECT queries

The review combines projection, country filters, ordering and pagination using north_american_cities. It occupies the position between lessons 4 and 6; SQLBolt labels it a review rather than Lesson 5.

Note. Use the values in the exercise table, not current population estimates. The Chicago comparison below obtains its longitude from the table, using a subquery instead of a literal coordinate.

01 · Canadian cities and populations

SQL 
SELECT city, population FROM north_american_cities WHERE country = 'Canada';
pandas 
result = north_american_cities.loc[north_american_cities['country'].eq('Canada'), ['city', 'population']]

02 · US cities, north to south

SQL 
SELECT city FROM north_american_cities WHERE country = 'United States' ORDER BY latitude DESC;
pandas 
result = north_american_cities.loc[north_american_cities['country'].eq('United States')].sort_values('latitude', ascending=False)[['city']]

03 · Cities west of Chicago, west to east

SQL 
SELECT city FROM north_american_cities
WHERE longitude < (SELECT longitude FROM north_american_cities WHERE city = 'Chicago')
ORDER BY longitude;
pandas 
chicago_lon = north_american_cities.loc[north_american_cities['city'].eq('Chicago'), 'longitude'].iloc[0]
result = north_american_cities.loc[north_american_cities['longitude'].lt(chicago_lon)].sort_values('longitude')[['city']]

04 · Two most populous Mexican cities

SQL 
SELECT city, population FROM north_american_cities
WHERE country = 'Mexico' ORDER BY population DESC LIMIT 2;
pandas 
result = north_american_cities.loc[north_american_cities['country'].eq('Mexico')].sort_values('population', ascending=False).head(2)[['city', 'population']]

05 · Third and fourth US cities by population

SQL 
SELECT city, population FROM north_american_cities
WHERE country = 'United States' ORDER BY population DESC LIMIT 2 OFFSET 2;
pandas 
result = north_american_cities.loc[north_american_cities['country'].eq('United States')].sort_values('population', ascending=False).iloc[2:4][['city', 'population']]
