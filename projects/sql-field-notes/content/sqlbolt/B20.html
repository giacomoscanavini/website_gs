Additional topic · Set operations

UNION appends and deduplicates rows; UNION ALL preserves duplicates. INTERSECT retains shared rows. EXCEPT returns left-side rows absent on the right. Set operations require compatible corresponding columns.

Note. No interactive tasks are listed on this topic page. The authored examples use non-null id values. Select and align columns before concatenating: pandas aligns column names, SQL aligns column positions. These examples are set semantics, not INTERSECT ALL or EXCEPT ALL.

This topic has no interactive task list. The following authored examples illustrate the source scenarios and operators.

01 · Union with duplicates

SQL 
SELECT id FROM a UNION ALL SELECT id FROM b;
pandas 
result = pd.concat([a[['id']], b[['id']]], ignore_index=True)

02 · Distinct union

SQL 
SELECT id FROM a UNION SELECT id FROM b;
pandas 
result = pd.concat([a[['id']], b[['id']]], ignore_index=True).drop_duplicates()

03 · Intersection

SQL 
SELECT id FROM a INTERSECT SELECT id FROM b;
pandas 
result = a[['id']].drop_duplicates().merge(b[['id']].drop_duplicates(), on='id')

04 · Left difference

SQL 
SELECT id FROM a EXCEPT SELECT id FROM b;
pandas 
result = a.loc[~a['id'].isin(b['id']), ['id']].drop_duplicates()
