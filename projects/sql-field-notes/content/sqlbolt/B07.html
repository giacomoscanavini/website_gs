SQLBolt / Lesson 7

OUTER JOINs

LEFT JOIN preserves the left table’s rows, including unmatched ones. RIGHT JOIN preserves the right side; FULL JOIN preserves both. SQLBolt’s exercise environment here uses LEFT JOIN.

Note. Place buildings on the left to retain empty buildings. DISTINCT is applied after selecting the building-role pair, not to employee names.

01 · Buildings occupied by employees

SQL 
SELECT DISTINCT building FROM employees WHERE building IS NOT NULL;
pandas 
result = employees.loc[employees['building'].notna(), ['building']].drop_duplicates()

02 · Every building and its capacity

SQL 
SELECT building_name, capacity FROM buildings;
pandas 
result = buildings[['building_name', 'capacity']].copy()

03 · Distinct roles per building, keeping empty buildings

SQL 
SELECT DISTINCT b.building_name, e.role FROM buildings b
LEFT JOIN employees e ON b.building_name = e.building;
pandas 
m = buildings.merge(employees, left_on='building_name', right_on='building', how='left')
result = m[['building_name', 'role']].drop_duplicates()
