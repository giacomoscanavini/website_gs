Additional topic · Subqueries

A subquery supplies a scalar, a list or a derived table to another query. A correlated subquery refers to the current outer row. IN and NOT IN can test membership in query results.

Note. No interactive tasks are listed on this SQLBolt topic page. The examples below are authored equivalents of its sales-associate and department scenarios. SQL NOT IN requires care if the subquery can return NULL.

This topic has no interactive task list. The following authored examples illustrate the source scenarios and operators.

01 · Salary above company-average generated revenue

SQL 
SELECT * FROM sales_associates
WHERE salary > (SELECT AVG(revenue_generated) FROM sales_associates);
pandas 
threshold = sales_associates['revenue_generated'].mean()
result = sales_associates.loc[sales_associates['salary'].gt(threshold)]

02 · Salary above own-department average revenue

SQL 
SELECT e.* FROM employees e
WHERE e.salary > (SELECT AVG(d.revenue_generated) FROM employees d
                  WHERE d.department = e.department);
pandas 
mean_revenue = employees.groupby('department')['revenue_generated'].transform('mean')
result = employees.loc[employees['salary'].gt(mean_revenue)]

transform broadcasts a group statistic back to the original rows. This example uses the topic’s employee schema, not the earlier studio employee schema.
