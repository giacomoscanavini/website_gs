Expressions and aliases

Expressions calculate values in a query; AS gives the result a readable name. Arithmetic can convert units, combine sales or identify even years.

Note. These tasks use the tutorial’s complete movie/boxoffice matches. A LEFT JOIN would be needed to retain movies with no BoxOffice row; do not silently treat unknown sales as zero.

01 · Combined sales in millions

SQL 
SELECT m.title, (b.domestic_sales + b.international_sales) / 1000000.0 AS sales_millions
FROM movies m JOIN boxoffice b ON m.id = b.movie_id;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
result = m.assign(sales_millions=(m['domestic_sales'] + m['international_sales']) / 1_000_000)[['title', 'sales_millions']]

02 · Ratings as percentages

SQL 
SELECT m.title, b.rating * 10.0 AS rating_percent
FROM movies m JOIN boxoffice b ON m.id = b.movie_id;
pandas 
m = movies.merge(boxoffice, left_on='id', right_on='movie_id', how='inner', validate='one_to_one')
result = m.assign(rating_percent=m['rating'] * 10)[['title', 'rating_percent']]

03 · Movies released in even years

SQL 
SELECT title, year FROM movies WHERE year % 2 = 0;
pandas 
result = movies.loc[movies['year'].mod(2).eq(0), ['title', 'year']]
