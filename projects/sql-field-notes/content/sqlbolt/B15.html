SQLBolt / Lesson 15

DELETE rows

DELETE removes matching rows but leaves the table schema. A statement without WHERE removes all rows.

Note. Use a disposable exercise database. When foreign keys exist, deletion may be blocked or have configured cascading effects; pandas has no equivalent built-in relational enforcement.

01 · Remove pre-2005 releases

SQL 
DELETE FROM movies WHERE year < 2005;
pandas 
movies = movies.loc[movies['year'].isna() | movies['year'].ge(2005)].copy()

02 · Remove Andrew Stanton films

SQL 
DELETE FROM movies WHERE director = 'Andrew Stanton';
pandas 
movies = movies.loc[movies['director'].isna() | movies['director'].ne('Andrew Stanton')].copy()
