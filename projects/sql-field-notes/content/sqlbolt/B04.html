DISTINCT, sorting and pagination

DISTINCT removes duplicate result rows. ORDER BY controls order, DESC reverses it, and LIMIT/OFFSET choose a slice after sorting.

Note. Without ORDER BY, do not rely on row order. When sort keys tie, add a unique secondary key for deterministic pagination.

01 · Unique directors in alphabetical order

SQL 
SELECT DISTINCT director FROM movies ORDER BY director;
pandas 
result = movies[['director']].drop_duplicates().sort_values('director')

02 · Four most recent releases

SQL 
SELECT * FROM movies ORDER BY year DESC LIMIT 4;
pandas 
result = movies.sort_values('year', ascending=False).head(4)

03 · First five alphabetical titles

SQL 
SELECT * FROM movies ORDER BY title LIMIT 5;
pandas 
result = movies.sort_values('title').head(5)

04 · Next five alphabetical titles

SQL 
SELECT * FROM movies ORDER BY title LIMIT 5 OFFSET 5;
pandas 
result = movies.sort_values('title').iloc[5:10]
