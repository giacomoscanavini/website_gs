SQLBolt / Lesson 13

INSERT rows

INSERT adds rows to a table. An explicit column list makes the relationship between fields and values clear and allows omitted columns to receive defaults.

Note. Run task 1 before task 2. The director, year and runtime below are illustrative inputs, not claimed film metadata. The sales and rating are the exercise’s fictional values, not real-world box-office facts. Pandas does not enforce SQL defaults or auto-increment rules.

01 · Add Toy Story 4

SQL 
INSERT INTO movies (title, director, year, length_minutes)
VALUES ('Toy Story 4', 'Example Director', 2019, 100);
pandas 
new_id = int(movies['id'].max()) + 1 if not movies.empty else 1
new_movie = pd.DataFrame([{'id': new_id, 'title': 'Toy Story 4', 'director': 'Example Director', 'year': 2019, 'length_minutes': 100}])
movies = pd.concat([movies, new_movie], ignore_index=True)

02 · Add its BoxOffice record

SQL 
INSERT INTO boxoffice (movie_id, rating, domestic_sales, international_sales)
SELECT id, 8.7, 340000000, 270000000 FROM movies WHERE title = 'Toy Story 4';
pandas 
movie_id = movies.loc[movies['title'].eq('Toy Story 4'), 'id'].iloc[0]
new_sales = pd.DataFrame([{'movie_id': movie_id, 'rating': 8.7, 'domestic_sales': 340_000_000, 'international_sales': 270_000_000}])
boxoffice = pd.concat([boxoffice, new_sales], ignore_index=True)

Select the inserted movie ID instead of assuming a fixed numeric ID. This example assumes the title occurs once.
