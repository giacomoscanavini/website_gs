SELECT queries 101

SELECT chooses the columns returned from a table. Naming columns controls the output schema; * returns every column. A projection does not remove duplicate rows.

Note. Pandas examples use lowercase SQLBolt column names and import pandas as pd. Each query is independent unless a write lesson says otherwise.

01 · Film titles

SQL 
SELECT title FROM movies;
pandas 
result = movies[['title']].copy()

02 · Film directors

SQL 
SELECT director FROM movies;
pandas 
result = movies[['director']].copy()

03 · Titles with directors

SQL 
SELECT title, director FROM movies;
pandas 
result = movies[['title', 'director']].copy()

04 · Titles with release years

SQL 
SELECT title, year FROM movies;
pandas 
result = movies[['title', 'year']].copy()

05 · Every movie column

SQL 
SELECT * FROM movies;
pandas 
result = movies.copy()
