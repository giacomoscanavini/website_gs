NULL and unmatched rows

IS NULL and IS NOT NULL test missing values. An unmatched outer-join row contains NULLs on the missing side. A missing value is not automatically equivalent to zero or an empty string.

Note. For a general anti-join, inspect a non-nullable key or an explicit merge indicator. Pandas merge can match missing keys to each other, unlike a SQL equality join.

01 · Employees without a building

SQL 
SELECT name, role FROM employees WHERE building IS NULL;
pandas 
result = employees.loc[employees['building'].isna(), ['name', 'role']]

02 · Buildings with no employees

SQL 
SELECT b.building_name FROM buildings b
LEFT JOIN employees e ON b.building_name = e.building WHERE e.building IS NULL;
pandas 
occupied = employees['building'].dropna()
result = buildings.loc[~buildings['building_name'].isin(occupied), ['building_name']]
