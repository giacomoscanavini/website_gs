CREATE TABLE and schemas

CREATE TABLE declares column names, types and optional constraints. The lesson introduces primary keys, uniqueness, NOT NULL, checks, foreign keys and defaults; the exercise table itself has no constraints.

Note. An empty typed DataFrame is only a schema-like analogue. It does not create a persistent database table, enforce primary/foreign keys or implement SQL constraints. Database is quoted because it is a reserved word in MySQL.

01 · Create the requested Database table

SQL 
CREATE TABLE `Database` (
    Name TEXT,
    Version FLOAT,
    Download_count INTEGER
);
pandas 
database = pd.DataFrame({'Name': pd.Series(dtype='string'), 'Version': pd.Series(dtype='Float64'), 'Download_count': pd.Series(dtype='Int64')})
