WHERE versus HAVING

WHERE filters individual rows before aggregation. HAVING filters grouped results after aggregation. Choose the clause according to whether the condition describes an input row or a group result.

Note. The engineer task can use WHERE before SUM. The HAVING form shown keeps the grouping concept visible; it does not imply that WHERE would be incorrect.

01 · Count artists without HAVING

SQL 
SELECT COUNT(*) AS artist_count FROM employees WHERE role = 'Artist';
pandas 
result = pd.DataFrame({'artist_count': [int(employees['role'].eq('Artist').sum())]})

02 · Employee count per role

SQL 
SELECT role, COUNT(*) AS employee_count FROM employees GROUP BY role;
pandas 
result = employees.groupby('role', dropna=False).size().reset_index(name='employee_count')

03 · Total engineer tenure

SQL 
SELECT role, SUM(years_employed) AS total_years
FROM employees GROUP BY role HAVING role = 'Engineer';
pandas 
g = employees.groupby('role', dropna=False)['years_employed'].sum(min_count=1).reset_index(name='total_years')
result = g.loc[g['role'].eq('Engineer')]
