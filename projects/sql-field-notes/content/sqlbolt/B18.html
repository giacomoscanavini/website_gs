SQLBolt / Lesson 18

DROP TABLE

DROP TABLE removes both the rows and the table definition. IF EXISTS avoids an error when the table is already absent.

Note. The order below follows SQLBolt’s tasks. In a real schema, handle referencing foreign keys before dropping a referenced table. Python del only removes a variable binding; it is not a database DROP.

01 · Drop Movies

SQL 
DROP TABLE movies;
pandas 
del movies

SQL

pandas
