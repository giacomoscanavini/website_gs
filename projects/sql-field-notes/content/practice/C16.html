1070 · First-year product sales

Keep every sale row in each product’s earliest sales year.

Pattern: Minimum per group / ties

Example

Product 1 has two sales in 2018 and one in 2019 → retain both 2018 rows.

Study solution

SQL 
SELECT s.product_id, s.year AS first_year, s.quantity, s.price
FROM Sales s JOIN (SELECT product_id, MIN(year) AS first_year FROM Sales GROUP BY product_id) f
ON s.product_id = f.product_id AND s.year = f.first_year;
pandas 
import pandas as pd

def sales_analysis(sales: pd.DataFrame) -> pd.DataFrame:
    first_year = sales.groupby('product_id')['year'].transform('min')
    return sales.loc[sales['year'].eq(first_year), ['product_id', 'year', 'quantity', 'price']].rename(columns={'year': 'first_year'})

Why it works

The minimum is broadcast to every product row. Equality retains ties, which is why drop_duplicates(product_id) would lose valid first-year sales.

Notes

Keep every sale from each product’s first year, including ties.

My approach
SQL 
WITH SalesII AS (
    SELECT
        product_id,
        year,
        RANK() OVER (
            PARTITION BY   product_id
            ORDER BY year ASC
        ) AS year_order,
        quantity,
        price
    FROM Sales
)
SELECT product_id, year AS first_year,   quantity, price
FROM SalesII
WHERE year_order = 1;
pandas 
import pandas as pd

def sales_analysis(sales: pd.DataFrame) -> pd.DataFrame:
    sales['year_order'] = sales.groupby(by='product_id')['year'].rank(method='min')
    sales = sales[sales['year_order'] == 1]
    sales = sales[['product_id', 'year', 'quantity', 'price']].rename(columns={'year': 'first_year'})
    return sales
