1393 · Capital gain/loss

Add sale proceeds and subtract purchase costs for each stock.

My submission

MySQL 
# Write your MySQL query statement below
WITH Operations AS (
    SELECT 
        stock_name,  
        CASE 
            WHEN operation = 'Buy' THEN -1 * price
            ELSE price
        END AS capital_gain_loss
    FROM Stocks
)

SELECT stock_name, SUM(capital_gain_loss) AS capital_gain_loss
FROM Operations
GROUP BY stock_name
pandas 
import pandas as pd

def capital_gainloss(stocks: pd.DataFrame) -> pd.DataFrame:
    flag = stocks['operation'] == 'Buy'
    stocks['price'][flag] = -1 * stocks['price']

    return stocks.groupby(by='stock_name').agg(
        capital_gain_loss = ('price', 'sum')
    ).reset_index()

How the submitted approach works

The SQL negates Buy prices with CASE, then sums by stock_name. The pandas implementation attempts the same sign change with chained assignment before grouping.

Implementation note. The pandas file uses chained assignment. It does not reliably update the original DataFrame and does not work as intended under pandas Copy-on-Write. A separate working variation is included below.
Working pandas variation · avoids chained assignment

Working alternative.

pandas 
import pandas as pd

def capital_gainloss(stocks: pd.DataFrame) -> pd.DataFrame:
    df = stocks.copy()
    buy = df['operation'].eq('Buy')
    df.loc[buy, 'price'] = -df.loc[buy, 'price']
    return df.groupby('stock_name', as_index=False).agg(
        capital_gain_loss=('price', 'sum')
    )
