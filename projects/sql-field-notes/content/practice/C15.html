1141 · User activity in a 30-day window

Count daily unique users over the inclusive 30-day interval ending 2019-07-27.

Pattern: Date filtering / distinct count

Example

June 28 and July 27 are included; June 27 and July 28 are excluded.

Study solution

SQL 
SELECT activity_date AS day, COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
  AND activity_type IN ('open_session', 'end_session', 'scroll_down', 'send_message')
GROUP BY activity_date;
pandas 
import pandas as pd

def user_activity(activity: pd.DataFrame) -> pd.DataFrame:
    a = activity.assign(activity_date=pd.to_datetime(activity['activity_date']))
    kinds = ['open_session', 'end_session', 'scroll_down', 'send_message']
    mask = a['activity_date'].between('2019-06-28', '2019-07-27') & a['activity_type'].isin(kinds)
    return a.loc[mask].groupby('activity_date', as_index=False).agg(active_users=('user_id', 'nunique')).rename(columns={'activity_date': 'day'})

Why it works

Thirty inclusive dates means end minus 29 days. Group only after filtering, then count each user at most once per day.

Notes

The range includes 28 June through 27 July. For timestamps, use an exclusive upper bound of 28 July.

SELECT
    activity_date   AS day,
    COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE
    DATEDIFF('2019-07-27',   activity_date) < 30 AND
    activity_date   <= '2019-07-27'   AND
    activity_type   IN ('open_session', 'end_session', 'scroll_down', 'send_message')
GROUP BY   activity_date;
pandas 
import pandas as pd

def user_activity(activity: pd.DataFrame) -> pd.DataFrame:
    good_activity   = ['open_session', 'end_session', 'scroll_down', 'send_message']
    bool_activity_type = activity['activity_type'].isin(good_activity)

    activity['activity_date'] =   pd.to_datetime(activity['activity_date'])
    end_date = pd.Timestamp('2019-07-27')
    start_date = end_date - pd.Timedelta(days=29)
    bool_activity_date = activity['activity_date'].between(start_date, end_date)

    bool_flag = bool_activity_type   &   bool_activity_date
    df =   activity[bool_flag]

    return df.groupby(by='activity_date').agg(
        active_users = ('user_id', 'nunique')
    ).reset_index().rename(columns={'activity_date': 'day'})
