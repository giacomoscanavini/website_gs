1075 · Project employees I

Return the rounded average experience per project.

Pattern: Join / average

Example

Experiences 2, 4 and 6 in one project → 4.00.

Study solution

SQL 
SELECT p.project_id, ROUND(AVG(e.experience_years), 2) AS average_years
FROM Project p LEFT JOIN Employee e ON p.employee_id = e.employee_id
GROUP BY p.project_id;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def project_employees_i(project: pd.DataFrame, employee: pd.DataFrame) -> pd.DataFrame:
    m = project.merge(employee, on='employee_id', how='left', validate='many_to_one')
    g = m.groupby('project_id', as_index=False).agg(average_years=('experience_years', 'mean'))
    g['average_years'] = g['average_years'].map(round_half_up)
    return g

Why it works

AVG and pandas mean both exclude missing experience values. The join attaches each employee’s experience to each project membership.

Notes

Average experience is computed over nonmissing experience values.

SELECT

FROM Project p
LEFT JOIN Employee e   ON p.employee_id = e.employee_id
GROUP BY p.project_id;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def project_employees_i(project: pd.DataFrame, employee: pd.DataFrame) -> pd.DataFrame:
    df =   project.merge(employee, on='employee_id', how='left')[['project_id', 'experience_years']]
    df =   df.groupby(by='project_id').agg(
        total_years = ('experience_years', 'sum'),
        n_employees = ('experience_years', 'count'),
    ).reset_index()
    df['average_years'] =   (df['total_years'] / df['n_employees']).map(round_half_up)
    return df[['project_id', 'average_years']]
