570 · Managers with at least five direct reports

Return the names of employees who have at least five direct reports.

Pattern: Grouped count / self-join

Illustrative example

Five employee rows have managerId 1 and four have managerId 2. When employee 1 is Ana and employee 2 is Bo, the result contains Ana only.

My solution

SQL 
WITH M AS (
    SELECT managerId, COUNT(*) AS nReports
    FROM Employee
    GROUP BY managerId
)
SELECT e.name
FROM Employee e
LEFT JOIN M ON e.id = M.managerId
WHERE M.nReports >= 5
pandas 
import pandas as pd
def find_managers(employee: pd.DataFrame) -> pd.DataFrame:
    reports = employee.groupby(by='managerId').agg(
        nReports = ('managerId', 'size')
    ).reset_index().rename(columns={'managerId': 'id'})
    df = employee.merge(reports, on='id', how='left')
    return df[df.nReports >= 5][['name']]

Why it works

Grouping by managerId counts each manager’s direct reports. Joining those counts back to Employee maps the manager ID to a name. The final threshold includes exactly five reports as well as larger teams.
