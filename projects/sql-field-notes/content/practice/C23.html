610 · Triangle judgement

Label a row Yes only if all three strict triangle inequalities hold.

Pattern: CASE / vectorization

Example

(3,4,5) → Yes; (1,2,3) → No.

Study solution

SQL 
SELECT x, y, z,
       CASE WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes' ELSE 'No' END AS triangle
FROM Triangle;
pandas 
import pandas as pd

def triangle_judgement(triangle: pd.DataFrame) -> pd.DataFrame:
    t = triangle.copy()
    valid = (t['x'] + t['y'] > t['z']) & (t['x'] + t['z'] > t['y']) & (t['y'] + t['z'] > t['x'])
    t['triangle'] = valid.map({True: 'Yes', False: 'No'})
    return t

Why it works

CASE corresponds to assigning a label from a boolean mask. Equality produces a degenerate triangle and must be rejected.

Notes

Side lengths are nonmissing. Every pairwise sum must be strictly greater than the remaining side.

My approach
SQL 
SELECT
    x, y, z,
    CASE
        WHEN x + y <= z THEN 'No'
        WHEN x + z <= y THEN 'No'
        WHEN y + z <= x THEN 'No'
        ELSE 'Yes'
    END AS triangle
FROM Triangle;
