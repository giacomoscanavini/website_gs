1174 · Immediate first deliveries

Among each customer’s first orders, calculate the percentage requested for the order date.

Pattern: First row per group

Example

Two customers whose first orders are immediate and scheduled → 50.00%, even if the first customer places many later orders.

Study solution

SQL 
WITH ranked AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date) AS rn
    FROM Delivery
)
SELECT ROUND(100.0 * AVG(CASE WHEN order_date = customer_pref_delivery_date THEN 1 ELSE 0 END), 2)
       AS immediate_percentage
FROM ranked WHERE rn = 1;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def immediate_food_delivery(delivery: pd.DataFrame) -> pd.DataFrame:
    d = delivery.assign(order_date=pd.to_datetime(delivery['order_date']), customer_pref_delivery_date=pd.to_datetime(delivery['customer_pref_delivery_date']))
    first = d.sort_values('order_date').drop_duplicates('customer_id', keep='first')
    value = 100 * first['order_date'].eq(first['customer_pref_delivery_date']).mean()
    return pd.DataFrame({'immediate_percentage': [round_half_up(value)]})

Why it works

Select the first order per customer before averaging. This gives each customer one vote, regardless of their total number of orders.

Notes

Each customer has a unique earliest order. A tie requires an explicit tie-break rule.

My approach
SQL 
WITH Orders AS (
    SELECT
        customer_id,
        CASE
            WHEN order_date =   customer_pref_delivery_date THEN 1
            ELSE 0
        END AS immediate,
        ROW_NUMBER() OVER (
            PARTITION BY   customer_id
            ORDER BY order_date ASC
        ) AS number
    FROM Delivery
)
SELECT ROUND(100 * SUM(immediate) / COUNT(immediate), 2) AS   immediate_percentage
FROM Orders
WHERE number = 1;

from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def immediate_food_delivery(delivery: pd.DataFrame) -> pd.DataFrame:
    delivery = delivery.assign(order_date=pd.to_datetime(delivery['order_date']),
                               customer_pref_delivery_date=pd.to_datetime(delivery['customer_pref_delivery_date'])).reset_index(drop=True)
    delivery['immediate'] =   delivery['order_date'] == delivery['customer_pref_delivery_date']
    idx_to_keep =   delivery.groupby(by='customer_id')['order_date'].idxmin()
    return   pd.DataFrame({'immediate_percentage': [round_half_up(100 * delivery['immediate'][idx_to_keep].mean(), 2)]})
