1667 · Fix names in a table

Uppercase the first character and lowercase the rest, ordered by user_id.

Pattern: String normalization

Example

"aLICE" → "Alice"; "b" → "B"; an empty string remains empty.

Study solution

SQL 
SELECT user_id, CONCAT(UPPER(SUBSTRING(name, 1, 1)), LOWER(SUBSTRING(name, 2))) AS name FROM Users ORDER BY user_id;
pandas 
import pandas as pd

def fix_names(users: pd.DataFrame) -> pd.DataFrame:
    result = users.copy()
    result['name'] = result['name'].str[:1].str.upper() + result['name'].str[1:].str.lower()
    return result.sort_values('user_id')

Why it works

Apply the transformation to the first character and remaining substring separately, not title case for every word.

Notes

Transform the first character and the remaining substring separately. Empty names remain empty.

pandas 
import pandas as pd

def fix_names(users: pd.DataFrame) -> pd.DataFrame:
    def fix_string(x):
        if pd.isna(x): return x
        if not x: return x
        if len(x) > 1: return x[0].upper() + x[1:].lower()
        else: return x[0].upper()
    users['name'] = users['name'].transform(fix_string)

    return   users.sort_values(by='user_id')
