1164 · Product price at a given date

Use the most recent price change on or before 2019-08-16, otherwise default to 10.

Pattern: As-of selection / default

Example

Product 1 changes to 20 on Aug 10 and 30 on Aug 17 → price 20 on Aug 16. A product first changed Aug 17 → 10.

Study solution

SQL 
WITH ranked AS (
    SELECT product_id, new_price, ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY change_date DESC) AS rn
    FROM Products WHERE change_date <= '2019-08-16'
), ids AS (SELECT DISTINCT product_id FROM Products)
SELECT i.product_id, COALESCE(r.new_price, 10) AS price FROM ids i
LEFT JOIN ranked r ON i.product_id = r.product_id AND r.rn = 1;
pandas 
import pandas as pd

def price_at_given_date(products: pd.DataFrame) -> pd.DataFrame:
    p = products.assign(change_date=pd.to_datetime(products['change_date']))
    valid = p.loc[p['change_date'].le(pd.Timestamp('2019-08-16'))]
    latest = valid.sort_values('change_date').drop_duplicates('product_id', keep='last')
    result = p[['product_id']].drop_duplicates().merge(latest[['product_id', 'new_price']], on='product_id', how='left')
    result['price'] = result['new_price'].fillna(10)
    return result[['product_id', 'price']]

Why it works

Filter the history to eligible dates first, then choose the latest remaining row. Start from all product IDs to retain products whose first change is later.

Notes

Prices are nonmissing, and a product has at most one change per date.

pandas 
import pandas as pd

def price_at_given_date(products: pd.DataFrame) -> pd.DataFrame:
    products = products.assign(change_date=pd.to_datetime(products['change_date']))
    ids = set(products.product_id)
    df = products[products['change_date'] <= '2019-08-16']
    df = df.sort_values(by=['product_id', 'change_date'], ascending=[True, False]).drop_duplicates('product_id').rename(columns={'new_price': 'price'})

    updated_ids = set(df.product_id)
    to_update = list(ids.difference(updated_ids))
    df1 = pd.DataFrame({'product_id':   to_update,
                        'price': [10 for x in to_update]})
    return   pd.concat([df[['product_id', 'price']], df1])
