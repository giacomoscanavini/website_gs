1581 · Customers who visited without transactions

Count visits without a transaction for each customer.

Pattern: Left join / unmatched rows / grouped count

Illustrative example

Customer 10 has visits 1 and 2; customer 20 has visit 3. Only visit 2 has a transaction, so the output is (customer_id 10, count_no_trans 1) and (customer_id 20, count_no_trans 1).

My solution

SQL 
SELECT v.customer_id, COUNT(*) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t ON v.visit_id = t.visit_id
WHERE t.transaction_id IS NULL
GROUP BY v.customer_id;
pandas 
import pandas as pd

def find_customers(visits: pd.DataFrame, transactions: pd.DataFrame) -> pd.DataFrame:
    df = visits.merge(transactions, on='visit_id', how='left')
    df = df[df.transaction_id.isna()]
    return df.groupby('customer_id').size().reset_index(name='count_no_trans')

Why it works

The left join retains every visit. Filter unmatched transaction IDs, then count the remaining visits per customer.

A missing joined transaction ID identifies a visit without a transaction, regardless of the amount field.

import pandas as pd

def find_customers(visits: pd.DataFrame, transactions: pd.DataFrame) -> pd.DataFrame:
    df = visits.merge(transactions, on='visit_id', how='left')
    df = df[df.amount.isna()]
    return df.groupby(by='customer_id')['amount'].agg(count_no_trans = 'size').reset_index()
