1158 · Market analysis I

Count each user’s orders in 2019, keeping users with no such orders.

My submission

MySQL 
# Write your MySQL query statement below
WITH Orders2019 AS (
    SELECT buyer_id, COUNT(*) AS orders_in_2019
    FROM Orders 
    WHERE order_date >= '2019-01-01' AND order_date <= '2019-12-31'
    GROUP BY buyer_id
)

SELECT 
    u.user_id AS buyer_id, 
    u.join_date, 
    COALESCE(o.orders_in_2019, 0) AS orders_in_2019
FROM Users u
LEFT JOIN Orders2019 o ON u.user_id = o.buyer_id
pandas 
import pandas as pd

def market_analysis(users: pd.DataFrame, orders: pd.DataFrame, items: pd.DataFrame) -> pd.DataFrame:
    orders = orders[(orders.order_date >= '2019-01-01') & (orders.order_date <= '2019-12-31')]
    df = orders.groupby(by='buyer_id').agg(
        orders_in_2019 = ('buyer_id', 'size')
    ).reset_index()

    df = users.merge(df, left_on='user_id', right_on='buyer_id', how='left')
    df = df[['user_id', 'join_date', 'orders_in_2019']]
    df = df.rename(columns={'user_id': 'buyer_id'})
    
    return df.fillna(0)

How the submitted approach works

Filter the order dates, count per buyer, and left-join the counts to Users. Missing order counts become zero.

Implementation note. The date filters use inclusive date-only endpoints. The pandas fillna(0) applies to the entire selected output, including join_date if that field is missing.
