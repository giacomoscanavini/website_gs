1517 · Users with valid emails

Match a letter-led local part containing letters, digits, _, . or -, with exactly the domain leetcode.com.

Pattern: Regular expressions

Example

a.b-2@leetcode.com is accepted; 2abc@leetcode.com and abc@LeetCode.com are rejected.

Study solution

SQL 
SELECT user_id, name, mail FROM Users
WHERE REGEXP_LIKE(mail, '^[A-Za-z][A-Za-z0-9_.-]*@leetcode[.]com$', 'c');
pandas 
import pandas as pd

def valid_emails(users: pd.DataFrame) -> pd.DataFrame:
    pattern = r'[A-Za-z][A-Za-z0-9_.-]*@leetcode[.]com'
    return users.loc[users['mail'].str.fullmatch(pattern, na=False)].copy()

Why it works

fullmatch requires the whole string to satisfy the pattern. [.] matches a literal period without double escaping, and the SQL c flag requests case-sensitive matching.

Notes

The domain must be exactly lowercase leetcode.com. This is the exercise’s restricted pattern, not a general email validator.
