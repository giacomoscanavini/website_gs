176 · Second highest salary

Return the second-highest distinct nonmissing salary, or one NULL result when absent.

Pattern: Distinct scalar / NULL

Example

[100,100,90] → 90; [100,100] → NULL/None.

Study solution

SQL 
SELECT MAX(salary) AS SecondHighestSalary FROM Employee WHERE salary < (SELECT MAX(salary) FROM Employee);
pandas 
import pandas as pd

def second_highest_salary(employee: pd.DataFrame) -> pd.DataFrame:
    salaries = employee['salary'].dropna().drop_duplicates().sort_values(ascending=False)
    value = salaries.iloc[1] if len(salaries) >= 2 else None
    return pd.DataFrame({'SecondHighestSalary': [value]})

Why it works

The maximum salary strictly below the overall maximum is the second distinct level. Preserve a one-row result rather than returning an empty DataFrame.

Notes

Rank distinct nonmissing salaries. Return a single missing value when fewer than two salaries exist.

My approach
SQL 
WITH
    Ranked AS (
        SELECT
            salary,
            ROW_NUMBER() OVER (PARTITION BY salary)   AS   ranks
        FROM Employee
        WHERE salary IS NOT NULL
    ),
    UniqueRanks AS (
        SELECT salary
        FROM Ranked
        WHERE ranks = 1
    ),
    Numbered AS (
        SELECT
            salary,
            ROW_NUMBER() OVER (ORDER BY salary DESC) AS numb
        FROM UniqueRanks
    )
SELECT (
    SELECT salary
    FROM Numbered
    WHERE numb = 2
) AS SecondHighestSalary;

import pandas as pd
def second_highest_salary(employee: pd.DataFrame) -> pd.DataFrame:
    unique_salaries = employee['salary'].dropna().drop_duplicates()
    second_highest = unique_salaries.sort_values(ascending=False)
    if len(second_highest) > 1:
        return   pd.DataFrame({'SecondHighestSalary': [second_highest.values[1]]})
    else:
        return   pd.DataFrame({'SecondHighestSalary': [None]})
