3497 · Analyze subscription conversion

Compare average free-trial and paid activity duration for users with both types.

My submission

MySQL 
# Write your MySQL query statement below
WITH Payments AS (
    SELECT 
        user_id, 
        ROUND(AVG(IF(activity_type='free_trial', activity_duration, NULL)), 2) AS trial_avg_duration,
        ROUND(AVG(IF(activity_type='paid', activity_duration, NULL)), 2) AS paid_avg_duration
    FROM UserActivity
    WHERE activity_type <> 'cancelled'
    GROUP BY user_id
    ORDER BY user_id ASC
) 

SELECT * 
FROM Payments
WHERE 
    paid_avg_duration IS NOT NULL
    AND trial_avg_duration IS NOT NULL
pandas 
import pandas as pd

def analyze_subscription_conversion(user_activity: pd.DataFrame) -> pd.DataFrame:
    def custom_func(x):
        free_flag = x['activity_type'] == 'free_trial'
        paid_flag = x['activity_type'] == 'paid'

        round2 = lambda x: round(x + 0.0001, 2)

        return pd.Series({
            'trial_avg_duration': round2(x['activity_duration'][free_flag].mean()), 
            'paid_avg_duration': round2(x['activity_duration'][paid_flag].mean()), 
        })

    df = user_activity.groupby(by='user_id').apply(custom_func).reset_index()

    return df.dropna()

How the submitted approach works

SQL computes conditional averages. The pandas group function selects both activity types and returns their means, then drops incomplete results.

Implementation note. The pandas submission adds 0.0001 before rounding. This is not a general exact-decimal rounding rule.
