1633 · Users registered in a contest

Compute contest participation as a percentage of all users and apply the specified tie-break.

Pattern: Group counts / percentage

Example

With 4 users, a contest with 3 registrations has 75.00%.

Study solution

SQL 
SELECT contest_id, ROUND(100.0 * COUNT(*) / (SELECT COUNT(*) FROM Users), 2) AS percentage
FROM Register GROUP BY contest_id ORDER BY percentage DESC, contest_id;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def users_percentage(users: pd.DataFrame, register: pd.DataFrame) -> pd.DataFrame:
    g = register.groupby('contest_id').size().reset_index(name='participants')
    g['percentage'] = (100 * g['participants'] / len(users)).map(round_half_up)
    return g[['contest_id', 'percentage']].sort_values(['percentage', 'contest_id'], ascending=[False, True])

Why it works

The denominator is the total user population, not the number of registration rows. Sorting uses descending percentage, then ascending contest ID.

Notes

Users must be nonempty. Registrations reference valid users, with one row per user–contest pair.
