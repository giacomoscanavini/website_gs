1683 · Invalid tweets

Return IDs whose content has more than 15 characters.

Pattern: Strings

Example

Exactly 15 characters is valid; 16 characters is invalid.

Study solution

SQL 
SELECT tweet_id FROM Tweets WHERE CHAR_LENGTH(content) > 15;
pandas 
import pandas as pd

def invalid_tweets(tweets: pd.DataFrame) -> pd.DataFrame:
    return tweets.loc[tweets['content'].str.len().gt(15), ['tweet_id']].copy()

Why it works

A vectorized string-length comparison avoids a temporary valid column and a row-level function.

Notes

Use character length, not byte length, to measure text.

def invalid_tweets(tweets: pd.DataFrame) -> pd.DataFrame:
    tweets['valid'] = tweets['content'].str.len()   <= 15

        else: return True
    tweets['valid'] =   tweets['content'].apply(is_valid)
    """
    df =   tweets[tweets.valid == False]
    return df[['tweet_id']]
