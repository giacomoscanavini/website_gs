1211 · Queries quality and percentage

Average rating/position per query and calculate the percentage with rating below 3.

Pattern: Row expressions / aggregation

Example

Rows (rating,position)=(4,2),(2,2) → quality 1.50 and poor-query percentage 50.00.

Study solution

SQL 
SELECT query_name, ROUND(AVG(rating / position), 2) AS quality,
       ROUND(100.0 * AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END), 2) AS poor_query_percentage
FROM Queries GROUP BY query_name;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def queries_stats(queries: pd.DataFrame) -> pd.DataFrame:
    q = queries.assign(quality_ratio=queries['rating'] / queries['position'], poor=queries['rating'].lt(3).astype(int))
    g = q.groupby('query_name', dropna=False, as_index=False).agg(quality=('quality_ratio', 'mean'), poor_query_percentage=('poor', 'mean'))
    g['quality'] = g['quality'].map(round_half_up)
    g['poor_query_percentage'] = (100 * g['poor_query_percentage']).map(round_half_up)
    return g

Why it works

Compute each row’s ratio before averaging; AVG(rating)/AVG(position) is not the same metric. The average of a 0/1 indicator is a fraction.

Notes

Positions must be positive. Results use half-up rounding.

    queries['poor'] = (queries['rating'] < 3) * 100

        quality = ('quality_ratio', 'mean'),
        poor_query_percentage   = ('poor',   'mean')

    df['poor_query_percentage']   = df['poor_query_percentage'].apply(round2)

import pandas as pd

def queries_stats(queries: pd.DataFrame) -> pd.DataFrame:
    queries['quality_ratio'] = queries['rating'] / queries['position']
    queries['poor'] = queries['rating'].apply(
        lambda x: 1 if x < 3 else 0
    )

    df = queries.groupby(by='query_name').agg(
        quality = ('quality_ratio', 'mean'),
        poor_query_percentage = ('poor', 'mean')
    ).reset_index()

    df['quality'] = df['quality'].round(2)
    df['poor_query_percentage'] = (100 * df['poor_query_percentage']).round(2)

    return df[['query_name', 'quality', 'poor_query_percentage']]
