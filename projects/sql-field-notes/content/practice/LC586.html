586 · Customer placing the largest number of orders

Return the customer number occurring most often in Orders.

My submission

MySQL 
# Write your MySQL query statement below
SELECT customer_number
FROM Orders
GROUP BY customer_number
ORDER BY COUNT(*) DESC
LIMIT 1
pandas 
import pandas as pd

def largest_orders(orders: pd.DataFrame) -> pd.DataFrame:
    return orders['customer_number'].mode().to_frame()

How the submitted approach works

SQL groups orders and keeps the largest count. The pandas submission uses the mode of customer_number.

Implementation note. The SQL returns one row; pandas mode() returns all tied modes. They agree when there is a unique winner.
