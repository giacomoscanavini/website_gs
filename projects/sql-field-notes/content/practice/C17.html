596 · Classes with at least five students

Return classes with five or more unique students.

Pattern: HAVING

Example

Class A with five unique students qualifies; class B with four does not.

Study solution

SQL 
SELECT class FROM Courses GROUP BY class HAVING COUNT(DISTINCT student) >= 5;
pandas 
import pandas as pd

def find_classes(courses: pd.DataFrame) -> pd.DataFrame:
    g = courses.groupby('class', as_index=False).agg(n_students=('student', 'nunique'))
    return g.loc[g['n_students'].ge(5), ['class']]

Why it works

HAVING filters group counts. In pandas, first create the aggregated frame and then filter it.

My approach
SQL 
WITH Classes AS (
    SELECT
        COUNT(DISTINCT student) AS nStudents,
        class
    FROM Courses
    GROUP BY class
)
SELECT class
FROM Classes
WHERE nStudents >= 5;
pandas 
import pandas as pd

def find_classes(courses: pd.DataFrame) -> pd.DataFrame:
    df = courses.groupby(by='class').agg(
        nStudents = ('student', 'nunique')
    ).reset_index()
    return   df[df.nStudents >= 5][['class']]
