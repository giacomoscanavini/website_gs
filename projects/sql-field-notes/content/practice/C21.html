1731 · Employees reporting to employees

For each manager, return direct-report count and rounded average report age.

Pattern: Self join / aggregation

Example

Manager 1 has reports aged 20 and 21 → reports_count 2 and average_age 21.

My solution

SQL 
WITH Reports AS (
    SELECT reports_to AS manager_id,
           COUNT(*) AS reports_count,
           ROUND(AVG(age)) AS average_age
    FROM Employees
    WHERE reports_to IS NOT NULL
    GROUP BY reports_to
)
SELECT r.manager_id AS employee_id, e.name, r.reports_count, r.average_age
FROM Reports r
LEFT JOIN Employees e ON r.manager_id = e.employee_id
ORDER BY r.manager_id;
pandas 
import pandas as pd

def count_employees(employees: pd.DataFrame) -> pd.DataFrame:
    by_manager = employees.groupby('reports_to', as_index=False).agg(
        reports_count=('employee_id', 'size'),
        average_age=('age', 'mean')
    )
    by_manager['average_age'] = (by_manager['average_age'] + 1e-12).round(0)
    df = by_manager.merge(employees[['employee_id', 'name']], how='left',
                          left_on='reports_to', right_on='employee_id')
    return df[['employee_id', 'name', 'reports_count', 'average_age']].sort_values('employee_id')

Why it works

Aggregate the report rows by reports_to, then attach the manager’s name. Employees without reports are excluded.

Notes

Only direct reports are counted. Return managers ordered by employee_id.

        reports_count=('employee_id', 'size'),
