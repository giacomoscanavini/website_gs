1148 · Article Views I

Return authors who viewed their own articles, without duplicates and sorted by ID.

Pattern: DISTINCT / sorting

Example

Qualifying author IDs [7, 3, 7] → id values [3, 7].

Study solution

SQL 
SELECT DISTINCT author_id AS id FROM Views WHERE author_id = viewer_id ORDER BY id;
pandas 
import pandas as pd

def article_views(views: pd.DataFrame) -> pd.DataFrame:
    result = views.loc[views['author_id'].eq(views['viewer_id']), ['author_id']]
    return result.drop_duplicates().rename(columns={'author_id': 'id'}).sort_values('id')

Why it works

Filter first, select the author column, then deduplicate. Deduplicating complete view records would not necessarily make author IDs unique.

My approach
SQL 
SELECT DISTINCT   author_id AS id
FROM Views
WHERE author_id = viewer_id
ORDER BY id ASC;
pandas 
import pandas as pd

def article_views(views: pd.DataFrame) -> pd.DataFrame:
    ids = sorted(views[views.author_id   == views.viewer_id].author_id.unique())
    return   pd.DataFrame({'id': ids})
