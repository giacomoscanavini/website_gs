626 · Exchange seats

Swap adjacent seat IDs and leave an unpaired final odd seat unchanged.

Pattern: CASE / parity

Example

Students A,B,C in seats 1,2,3 → output seats 1=B, 2=A, 3=C.

Study solution

SQL 
SELECT CASE WHEN id % 2 = 0 THEN id - 1
            WHEN id < (SELECT MAX(id) FROM Seat) THEN id + 1
            ELSE id END AS id, student
FROM Seat ORDER BY id;
pandas 
import pandas as pd

def exchange_seats(seat: pd.DataFrame) -> pd.DataFrame:
    ids = seat['id']
    swapped = ids + 2 * ids.mod(2) - 1
    new_ids = swapped.where(~(ids.eq(ids.max()) & ids.mod(2).eq(1)), ids)
    return seat.assign(id=new_ids).sort_values('id')

Why it works

Even IDs move down one and odd IDs move up one. Restore the last ID when it is odd, then sort by the new seat IDs.

Notes

Seat IDs are contiguous and start at 1. An unpaired final odd seat stays unchanged.

WITH NStudents AS (
    SELECT COUNT(id) AS length
    FROM Seat
)
SELECT
    CASE
        WHEN id % 2 = 0 THEN id-1
        WHEN id <> (SELECT length FROM   NStudents) AND id % 2 = 1 THEN id+1
        ELSE id
    END AS id,
    student
FROM Seat
ORDER BY id ASC;
pandas 
import pandas as pd
def exchange_seats(seat: pd.DataFrame) -> pd.DataFrame:
    last_id = seat.id.max()
    def swap_ids(x):
        if x % 2 == 0: return x - 1
        else:
            if x == last_id: return x
            else: return x + 1
    seat['id'] = seat['id'].transform(swap_ids)
    return   seat.sort_values(by='id', ascending=True)
