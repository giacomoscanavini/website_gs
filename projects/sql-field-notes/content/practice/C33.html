585 · Investments in 2016

Sum tiv_2016 when tiv_2015 is shared and the (lat, lon) location is unique.

Pattern: Window counts / duplicate masks

Example

Two rows share tiv_2015=10 and have distinct unique locations with tiv_2016 values 20 and 30 → sum 50.00.

Study solution

SQL 
WITH marked AS (
    SELECT *, COUNT(*) OVER (PARTITION BY tiv_2015) AS value_count,
           COUNT(*) OVER (PARTITION BY lat, lon) AS location_count FROM Insurance
)
SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016 FROM marked
WHERE value_count > 1 AND location_count = 1;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def find_investments(insurance: pd.DataFrame) -> pd.DataFrame:
    shared_value = insurance['tiv_2015'].duplicated(keep=False)
    unique_location = ~insurance[['lat', 'lon']].duplicated(keep=False)
    total = insurance.loc[shared_value & unique_location, 'tiv_2016'].sum(min_count=1)
    return pd.DataFrame({'tiv_2016': [round_half_up(total)]})

Why it works

Calculate both criteria on the complete input before filtering. A location is unique as a pair, not by requiring latitude and longitude each to be unique separately.

Notes

Criterion fields are nonmissing. When no row qualifies, return a missing total, matching SQL SUM.

WITH
    NonUniqueTIV AS (
        SELECT tiv_2015
        FROM Insurance
        GROUP BY tiv_2015
        HAVING COUNT(*) > 1
    ),
    UniqueCity AS (
        SELECT MIN(pid) AS pid
        FROM Insurance
        GROUP BY lat, lon
        HAVING COUNT(*) = 1
    )

SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016
FROM Insurance
WHERE pid IN (SELECT pid FROM UniqueCity) AND tiv_2015 IN (SELECT tiv_2015 FROM NonUniqueTIV);
