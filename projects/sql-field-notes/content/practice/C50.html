1934 · Confirmation rate

For each signed-up user, divide confirmed actions by confirmation requests and round to two decimals. Users without requests receive zero.

Pattern: Left join / conditional count / ratio

Illustrative example

User 1 has two confirmed actions and one timeout, user 2 has no requests, and user 3 has one confirmed action. Their rates are 0.67, 0.00 and 1.00.

My solution

SQL 
WITH Rate AS (
    SELECT
        s.user_id,
        CASE
            WHEN c.action = 'confirmed' THEN 1
            ELSE 0
        END AS boolean
    FROM Signups s
    LEFT JOIN Confirmations c ON s.user_id = c.user_id
)
SELECT user_id, ROUND(SUM(boolean)/COUNT(boolean), 2) AS confirmation_rate
FROM Rate
GROUP BY user_id
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def confirmation_rate(signups: pd.DataFrame, confirmations: pd.DataFrame) -> pd.DataFrame:
    df = signups.merge(confirmations, on='user_id', how='left')[['user_id', 'action']]
    df['confirmation_rate'] = df.action.eq('confirmed').fillna(False)
    df = df.groupby('user_id', as_index=False).agg(
        total=('confirmation_rate', 'size'),
        positive=('confirmation_rate', 'sum')
    )
    df['confirmation_rate'] = (df['positive'] / df['total']).map(round_half_up)
    return df[['user_id', 'confirmation_rate']]

Why it works

The left join retains every signup. CASE or the pandas comparison assigns 1/True to confirmed actions and 0/False otherwise. Summing gives the confirmed count and counting rows gives the denominator. A user without requests has one unmatched row with a zero flag, producing 0/1 = 0.

Users with no confirmations have rate zero. Rates use half-up rounding to two decimal places.

import pandas as pd

def confirmation_rate(signups: pd.DataFrame, confirmations: pd.DataFrame) -> pd.DataFrame:
    df = signups.merge(confirmations, on='user_id', how='left')[['user_id', 'action']]
    df['confirmation_rate'] = df.action == 'confirmed'

    df = df[['user_id', 'confirmation_rate']].groupby(by='user_id').agg(
        total = ('confirmation_rate', 'size'),
        positive = ('confirmation_rate', 'sum')
    ).reset_index()

    df['confirmation_rate'] = (df['positive'] / df['total']).round(2)
    return df[['user_id', 'confirmation_rate']]
