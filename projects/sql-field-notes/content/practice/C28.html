1978 · Low-salary employees whose manager left

Return employees below 30000 whose nonmissing manager ID is absent from Employees.

Pattern: Anti-join / NULL

Example

Employee 1 has salary 25000 and manager 99, but ID 99 is absent → include 1. Missing manager_id → exclude.

Study solution

SQL 
SELECT e.employee_id FROM Employees e
WHERE e.salary < 30000 AND e.manager_id IS NOT NULL
  AND NOT EXISTS (SELECT 1 FROM Employees m WHERE m.employee_id = e.manager_id)
ORDER BY e.employee_id;
pandas 
import pandas as pd

def find_employees(employees: pd.DataFrame) -> pd.DataFrame:
    mask = employees['salary'].lt(30000) & employees['manager_id'].notna() & ~employees['manager_id'].isin(employees['employee_id'])
    return employees.loc[mask, ['employee_id']].sort_values('employee_id')

Why it works

An absent manager record is different from no manager assigned. Exclude missing manager IDs before the anti-membership test.

Notes

Ignore missing manager IDs, then check whether each remaining manager is absent from the employee table.

My approach
SQL 
WITH ManagersLeftID AS (
    SELECT manager_id
    FROM Employees
    WHERE manager_id NOT IN (SELECT employee_id FROM Employees)
)
SELECT employee_id
FROM Employees
WHERE manager_id IN (SELECT manager_id FROM ManagersLeftID)   AND   salary < 30000
ORDER BY employee_id   ASC;

import pandas as pd
def find_employees(employees: pd.DataFrame) -> pd.DataFrame:
    flag_lowSalary = employees.salary <   30000
    flag_hasManager = ~employees.manager_id.isna()
    flag_managerLeft = ~employees['manager_id'].isin(employees['employee_id'])
    flag_ = flag_lowSalary &   flag_hasManager & flag_managerLeft
    return   employees[flag_][['employee_id']].sort_values(by='employee_id', ascending=True)
