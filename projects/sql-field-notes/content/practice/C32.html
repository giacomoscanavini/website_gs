602 · Most accepted friends

Count every person’s appearance at either end of an accepted friendship and return the maximum.

Pattern: UNION ALL / frequency

Example

Accepted pairs (1,2),(1,3),(2,3),(3,4) → user 3 has 3 friends.

Study solution

SQL 
WITH endpoints AS (
    SELECT requester_id AS id FROM RequestAccepted
    UNION ALL SELECT accepter_id FROM RequestAccepted
)
SELECT id, COUNT(*) AS num FROM endpoints GROUP BY id ORDER BY num DESC, id LIMIT 1;
pandas 
import pandas as pd

def most_friends(request_accepted: pd.DataFrame) -> pd.DataFrame:
    ids = pd.concat([request_accepted['requester_id'], request_accepted['accepter_id']], ignore_index=True)
    counts = ids.value_counts().rename_axis('id').reset_index(name='num')
    return counts.sort_values(['num', 'id'], ascending=[False, True]).head(1)

Why it works

Each friendship adds one connection to both endpoint users. Pooling endpoints turns a two-sided counting problem into a single frequency count.

Notes

Each friendship appears once. Count both endpoints; a tied maximum is resolved by the smaller ID.

My approach
SQL 
WITH
    TableRequest AS (
        SELECT
              requester_id AS id,
            COUNT(*) AS askedApproved
        FROM RequestAccepted
        GROUP BY   requester_id
    ),
    TableAccepted   AS (
        SELECT
              accepter_id AS id,
            COUNT(*) AS receivedApproved
        FROM RequestAccepted
        GROUP BY accepter_id
    ),
    PooledUsers AS (
        SELECT DISTINCT   requester_id AS id FROM RequestAccepted
        UNION
        SELECT DISTINCT   accepter_id AS id FROM RequestAccepted
    ),
    Users AS (
        SELECT DISTINCT id
        FROM PooledUsers
    ),
    Numbers AS (
        SELECT
            u.id,
            COALESCE(ta.receivedApproved, 0) + COALESCE(tr.askedApproved, 0) AS num
        FROM Users u
        LEFT JOIN   TableAccepted ta ON u.id = ta.id
        LEFT JOIN   TableRequest tr ON u.id = tr.id
    )
SELECT id, num
FROM Numbers
ORDER BY num DESC, id
LIMIT 1;
