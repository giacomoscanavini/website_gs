1484 · Products sold by date

For each date, count unique products and join their sorted names with commas.

Pattern: Distinct aggregation / string concatenation

Example

One day has [Tea,Coffee,Tea] → num_sold 2, products "Coffee,Tea".

Study solution

SQL 
SELECT sell_date, COUNT(DISTINCT product) AS num_sold,
       GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') AS products
FROM Activities GROUP BY sell_date ORDER BY sell_date;
pandas 
import pandas as pd

def categorize_products(activities: pd.DataFrame) -> pd.DataFrame:
    unique = activities[['sell_date', 'product']].drop_duplicates()
    return unique.groupby('sell_date', as_index=False).agg(
        num_sold=('product', 'size'), products=('product', lambda s: ','.join(sorted(s)))).sort_values('sell_date')

Why it works

Deduplicate date-product pairs before counting. Sort product names inside each date group, and sort dates separately for the output.

Notes

Product names are nonmissing. GROUP_CONCAT length is limited by the server’s group_concat_max_len setting.

import pandas as pd

def categorize_products(activities: pd.DataFrame) -> pd.DataFrame:
    activities.drop_duplicates(keep='first', inplace=True)
    
    def concat_string(x):
        x.sort_values(ascending=True, inplace=True)
        return ','.join(x)
    
    df = activities.groupby(by='sell_date').agg(
        num_sold = ('product', 'size'),
        products = ('product', concat_string)
    ).reset_index()

    return df
