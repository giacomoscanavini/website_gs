601 · Human traffic of stadium

Keep crowded stadium records that belong to runs of at least three consecutive IDs.

My submission

MySQL 
# Write your MySQL query statement below
WITH 
    CrowdedDays AS (
        SELECT  
            id, visit_date, people,
            id - ROW_NUMBER() OVER (ORDER BY id) AS group_num
        FROM Stadium 
        WHERE people >= 100
    ),
    ValidGroups AS (
        SELECT group_num
        FROM CrowdedDays
        GROUP BY group_num
        HAVING COUNT(*) >= 3
    )

SELECT 
    c.id, c.visit_date, c.people
FROM CrowdedDays c
JOIN ValidGroups v ON c.group_num = v.group_num
ORDER BY c.visit_date ASC
pandas 
import pandas as pd

def human_traffic(stadium: pd.DataFrame) -> pd.DataFrame:
    df = stadium[stadium.people >= 100]
    df = df.reset_index(drop=True)
    df['groups'] = df['id'] - (df.index + 1)

    valid_groups = df.groupby(by='groups').agg(
        valid = ('groups', 'size')
    ).reset_index()
    valid_groups = valid_groups[valid_groups['valid'] >= 3]

    df = df.merge(valid_groups, on='groups', how='inner')
    return df[['id', 'visit_date', 'people']].sort_values(by='visit_date', ascending=True)

How the submitted approach works

After filtering people >= 100, subtract a sequential row number from id. Consecutive IDs share the same difference. Retain groups with at least three rows.

Implementation note. The pandas submission uses current row order to construct groups. It requires the input to already be sorted by id; the SQL explicitly orders by id.
