1280 · Students and examinations

Return every student–subject combination with its exam attendance count, including zero attendance.

Pattern: Cross join / grouped count / zero fill

Illustrative example

Ana and Bo each take Math and SQL. Ana has two Math records; Bo has one SQL record. The four output rows have counts Ana–Math 2, Ana–SQL 0, Bo–Math 0 and Bo–SQL 1.

My solution

SQL 
SELECT s.student_id, s.student_name, su.subject_name, COUNT(e.student_id) AS attended_exams
FROM Students s
CROSS JOIN Subjects su
LEFT JOIN Examinations e ON s.student_id = e.student_id AND su.subject_name = e.subject_name
GROUP BY s.student_id, s.student_name, su.subject_name
ORDER BY s.student_id, s.student_name, su.subject_name
pandas 
import pandas as pd

def students_and_examinations(students: pd.DataFrame, subjects: pd.DataFrame, examinations: pd.DataFrame) -> pd.DataFrame:
    df = students.merge(subjects, how='cross')
    exam_count = examinations.groupby(['student_id', 'subject_name']).size().reset_index(name='attended_exams')
    df = df.merge(exam_count, on=['student_id', 'subject_name'], how='left')
    df['attended_exams'] = df['attended_exams'].fillna(0).astype(int)
    return df[['student_id', 'student_name', 'subject_name', 'attended_exams']].sort_values(['student_id', 'subject_name'])

Why it works

The cross join creates the complete student–subject grid. SQL counts matched examination student_id values, so unmatched pairs count as zero. Pandas counts exams first, merges the counts into the grid, fills missing values with zero and sorts the result.

The cross join includes every student–subject pair. Missing exam counts are integer zeros.

import pandas as pd

def students_and_examinations(students: pd.DataFrame, subjects: pd.DataFrame, examinations: pd.DataFrame) -> pd.DataFrame:
    df = students.merge(subjects, how='cross')

    exam_count = examinations.groupby(by=['student_id', 'subject_name']).agg(
        attended_exams = ('subject_name', 'count')
    ).reset_index()

    df = df.merge(exam_count, on=['student_id', 'subject_name'], how='left').fillna(0)
    return df.sort_values(['student_id', 'subject_name'])
