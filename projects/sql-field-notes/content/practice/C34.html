185 · Department top three salaries

Keep all employees whose salary is among the three highest distinct salaries in their department.

Pattern: DENSE_RANK / join

Example

Department salaries [100,100,90,80,70] → retain the first four employees (three distinct salary levels).

Study solution

SQL 
WITH ranked AS (
    SELECT *, DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC) AS salary_rank FROM Employee
)
SELECT d.name AS Department, r.name AS Employee, r.salary AS Salary
FROM ranked r JOIN Department d ON r.departmentId = d.id WHERE r.salary_rank <= 3;
pandas 
import pandas as pd

def top_three_salaries(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    rank = employee.groupby('departmentId')['salary'].rank(method='dense', ascending=False)
    chosen = employee.loc[rank.le(3)].rename(columns={'name': 'Employee', 'salary': 'Salary'})
    dept = department.rename(columns={'id': 'departmentId', 'name': 'Department'})
    result = chosen.merge(dept, on='departmentId', how='inner', validate='many_to_one')
    return result[['Department', 'Employee', 'Salary']]

Why it works

DENSE_RANK gives equal salaries equal rank without gaps. ROW_NUMBER would arbitrarily cut ties; RANK can skip rank values after a tie.

Notes

Every employee references an existing department. Dense ranking retains all salary ties.

WITH Ranked AS (
    SELECT
        id, name, salary,   departmentId,
        DENSE_RANK() OVER (
            PARTITION BY   departmentId ORDER BY salary DESC
        ) AS ranked
    FROM Employee
    ORDER BY   departmentId ASC, salary DESC
)
SELECT
    d.name AS Department,
    r.name AS Employee,
    r.salary AS Salary
FROM Ranked r
JOIN Department   d ON r.departmentId = d.id
WHERE r.ranked <= 3;
pandas 
import pandas as pd
def top_three_salaries(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    employee['ranked'] = employee.groupby(by='departmentId')['salary'].rank(method='dense', ascending=False)
    employee =   employee[employee.ranked <= 3]
    df =   employee.merge(department, left_on='departmentId', right_on='id', suffixes=['_x', '_y'])
    df = df.rename(columns={
        'name_x': 'Employee',
        'name_y': 'Department',
        'salary': 'Salary',
    })
    return df[['Department', 'Employee', 'Salary']]
