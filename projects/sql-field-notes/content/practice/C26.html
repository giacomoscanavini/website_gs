1204 · Last person to fit in the bus

Return the final person in queue order whose prefix weight does not exceed 1000.

Pattern: Cumulative sum

Example

Queue weights [400,400,300] → the second person is last to board.

Study solution

SQL 
WITH cumulative AS (
    SELECT person_name, turn, SUM(weight) OVER (ORDER BY turn ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS running_weight
    FROM Queue
)
SELECT person_name FROM cumulative WHERE running_weight <= 1000 ORDER BY turn DESC LIMIT 1;
pandas 
import pandas as pd

def last_passenger(queue: pd.DataFrame) -> pd.DataFrame:
    q = queue.sort_values('turn')
    return q.loc[q['weight'].cumsum().le(1000), ['person_name']].tail(1)

Why it works

Compute a cumulative sum after sorting, not a total grouped sum. Positive weights make feasibility a prefix condition.

Notes

Queue turns are unique and weights are positive. The cumulative window follows turn order.

pandas 
import pandas as pd

def last_passenger(queue: pd.DataFrame) -> pd.DataFrame:
    queue.sort_values(by='turn', ascending=True, inplace=True)
    queue['cumsum_weight'] = queue['weight'].cumsum()
    return   queue[queue.cumsum_weight <= 1000].tail(1)[['person_name']]
