619 · Biggest single number

Return the largest value occurring exactly once, or a one-row missing result.

Pattern: Frequency / scalar result

Example

Numbers [1,1,3,4,4] → 3. Numbers [1,1] → NULL/None.

Study solution

SQL 
SELECT MAX(num) AS num FROM (
    SELECT num FROM MyNumbers GROUP BY num HAVING COUNT(*) = 1
) singles;
pandas 
import pandas as pd

def biggest_single_number(my_numbers: pd.DataFrame) -> pd.DataFrame:
    s = my_numbers.loc[~my_numbers['num'].duplicated(keep=False), 'num'].dropna()
    return pd.DataFrame({'num': [s.max() if not s.empty else None]})

Why it works

Unlike drop_duplicates(), duplicated(keep=False) identifies every member of a duplicate group. The outer aggregate ensures one output row even when nothing qualifies.

My approach
SQL 
WITH Frequency AS (
    SELECT
        num,
        COUNT(*) AS frequency
    FROM MyNumbers
    GROUP BY num
)
SELECT MAX(num) AS num
FROM Frequency
WHERE frequency = 1;
pandas 
import pandas as pd

def biggest_single_number(my_numbers: pd.DataFrame) -> pd.DataFrame:
    df =   my_numbers.groupby(by='num').agg(
        freq = ('num', 'size')
    ).reset_index()
    return   pd.DataFrame({'num': df[df.freq == 1][['num']].max()})
