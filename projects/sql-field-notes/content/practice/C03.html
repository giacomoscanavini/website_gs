595 · Big countries

Return a country if its area or population reaches the stated threshold.

Pattern: Filtering

Example

Area 3,100,000 with population 1,000,000 qualifies; area 100 with population 30,000,000 also qualifies.

Study solution

SQL 
SELECT name, population, area FROM World WHERE area >= 3000000 OR population >= 25000000;
pandas 
import pandas as pd

def big_countries(world: pd.DataFrame) -> pd.DataFrame:
    mask = world['area'].ge(3_000_000) | world['population'].ge(25_000_000)
    return world.loc[mask, ['name', 'population', 'area']].copy()

Why it works

This is OR, not AND. Preserve the requested output column order.
