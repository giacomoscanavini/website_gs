1045 · Customers who bought every product

Return customers who have purchased all keys listed in Product.

Pattern: Relational division / membership

Example

Catalog {A,B}; customer 1 buys A,B; customer 2 buys A,X → only customer 1 qualifies.

Study solution

SQL 
SELECT DISTINCT c.customer_id FROM Customer c
WHERE NOT EXISTS (
    SELECT 1 FROM Product p WHERE NOT EXISTS (
        SELECT 1 FROM Customer bought
        WHERE bought.customer_id = c.customer_id AND bought.product_key = p.product_key
    )
);
pandas 
import pandas as pd

def find_customers(customer: pd.DataFrame, product: pd.DataFrame) -> pd.DataFrame:
    keys = product['product_key'].dropna().drop_duplicates()
    eligible = customer.loc[customer['product_key'].isin(keys)]
    counts = eligible.groupby('customer_id')['product_key'].nunique()
    ids = customer[['customer_id']].drop_duplicates()
    mask = ids['customer_id'].map(counts).fillna(0).eq(len(keys))
    return ids.loc[mask].copy()

Why it works

There must not exist a catalog product that the customer has not bought. The pandas version counts only catalog keys before comparing with catalog size.

Notes

Count distinct purchased keys that belong to the product catalogue.

My approach

SELECT c.customer_id
FROM Customer c
GROUP BY c.customer_id
HAVING (SELECT COUNT(*) FROM Product) = COUNT(DISTINCT CASE
    WHEN c.product_key IN (SELECT product_key FROM Product) THEN c.product_key END);
pandas 
import pandas as pd

def find_customers(customer: pd.DataFrame, product: pd.DataFrame) -> pd.DataFrame:
    nProducts = product['product_key'].nunique()
    customer_ids = customer[['customer_id']].drop_duplicates()
    customer = customer[customer['product_key'].isin(product['product_key'])]
    df = customer.groupby(by='customer_id').agg(
        nSold = ('product_key', 'nunique')
    ).reset_index()
    df = customer_ids.merge(df, on='customer_id', how='left').fillna({'nSold': 0})
    return df[df.nSold == nProducts][['customer_id']]
