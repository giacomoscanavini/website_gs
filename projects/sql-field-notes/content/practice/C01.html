1757 · Recyclable and low-fat products

Return product IDs that satisfy both Y flags.

Pattern: Filtering

Example

For IDs 1=(Y,Y), 2=(Y,N), 3=(N,Y), the result is product_id 1.

Study solution

SQL 
SELECT product_id FROM Products WHERE low_fats = 'Y' AND recyclable = 'Y';
pandas 
import pandas as pd

def find_products(products: pd.DataFrame) -> pd.DataFrame:
    mask = products['low_fats'].eq('Y') & products['recyclable'].eq('Y')
    return products.loc[mask, ['product_id']].copy()

Why it works

Combine elementwise conditions with & in pandas; parenthesize comparisons. Selecting a list of column names preserves a DataFrame.
