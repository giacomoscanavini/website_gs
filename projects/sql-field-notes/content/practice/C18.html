1729 · Followers count

Return each user’s distinct follower count.

Pattern: Aggregation / sorting

Example

User 2 followed by [1,3,3] → followers_count 2.

Study solution

SQL 
SELECT user_id, COUNT(DISTINCT follower_id) AS followers_count FROM Followers GROUP BY user_id ORDER BY user_id;
pandas 
import pandas as pd

def count_followers(followers: pd.DataFrame) -> pd.DataFrame:
    return followers.groupby('user_id', as_index=False).agg(followers_count=('follower_id', 'nunique')).sort_values('user_id')

Why it works

Group by the followed user and count distinct follower IDs. Explicit sorting makes presentation deterministic.

Notes

Return one row per user, ordered by user_id.
