584 · Find customer referee

Keep customers not referred by ID 2, including missing referee IDs.

Pattern: Filtering / NULL

Example

Referees [2, NULL, 7] → keep the second and third customers.

Study solution

SQL 
SELECT name FROM Customer WHERE referee_id <> 2 OR referee_id IS NULL;
pandas 
import pandas as pd

def find_customer_referee(customer: pd.DataFrame) -> pd.DataFrame:
    mask = customer['referee_id'].isna() | customer['referee_id'].ne(2)
    return customer.loc[mask, ['name']].copy()

Why it works

SQL comparisons with NULL are unknown, so the explicit IS NULL branch is essential. The pandas missing-value branch also works with nullable extension dtypes.
