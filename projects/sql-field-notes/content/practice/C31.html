1321 · Restaurant growth

Compute seven-calendar-day spending totals and daily averages, starting when the first full window is available.

Pattern: Daily aggregation / rolling calendar window

Example

Two visits totaling 100 each day for seven days → rolling amount 700 and average_amount 100.00.

Study solution

SQL 
WITH daily AS (
    SELECT visited_on, SUM(amount) AS amount FROM Customer GROUP BY visited_on
), rolled AS (
    SELECT visited_on,
           SUM(amount) OVER (ORDER BY visited_on RANGE BETWEEN INTERVAL 6 DAY PRECEDING AND CURRENT ROW) AS amount,
           MIN(visited_on) OVER () AS first_day
    FROM daily
)
SELECT visited_on, amount, ROUND(amount / 7.0, 2) AS average_amount
FROM rolled WHERE visited_on >= DATE_ADD(first_day, INTERVAL 6 DAY) ORDER BY visited_on;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def restaurant_growth(customer: pd.DataFrame) -> pd.DataFrame:
    c = customer.assign(visited_on=pd.to_datetime(customer['visited_on']))
    daily = c.groupby('visited_on')['amount'].sum().sort_index()
    if daily.empty:
        return pd.DataFrame(columns=['visited_on', 'amount', 'average_amount'])
    rolled = daily.rolling('7D', closed='right').sum()
    rolled = rolled.loc[rolled.index >= daily.index.min() + pd.Timedelta(days=6)]
    result = rolled.rename('amount').reset_index()
    result['average_amount'] = (result['amount'] / 7).map(round_half_up)
    return result

Why it works

Collapse multiple customers on the same day before rolling. The time window includes the current date plus the preceding six dates. Divide by seven, not by the number of customer rows.

Notes

Dates are normalized calendar dates. Use a seven-day window, with missing dates contributing zero, and report dates present in the data.

WITH Rolling AS (
    SELECT
        DISTINCT visited_on,
        SUM(amount) OVER (
            ORDER BY visited_on RANGE BETWEEN   INTERVAL 6 DAY   PRECEDING AND CURRENT ROW
        ) AS rolling_amount,
        MIN(visited_on) OVER () AS first_date
    FROM Customer
)
SELECT
    visited_on,
      rolling_amount AS amount,
    ROUND(rolling_amount   / 7, 2) AS average_amount
FROM Rolling
WHERE visited_on >= DATE_ADD(first_date, INTERVAL 6 DAY)
ORDER BY visited_on;

import pandas as pd

def restaurant_growth(customer: pd.DataFrame) -> pd.DataFrame:
    customer = customer.groupby(by='visited_on', as_index=False)['amount'].sum()

    nDays = 7
    customer['amount'] = customer.amount.rolling(nDays).sum()
    customer['average_amount'] = (customer.amount / nDays).round(2)

    return customer.dropna()
