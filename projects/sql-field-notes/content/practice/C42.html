1378 · Replace employee ID with the unique identifier

Return each employee’s unique identifier and name, keeping employees without an assigned identifier.

Pattern: Outer join / preserve unmatched rows

Illustrative example

Employees are Ana (id 1), Bo (id 2) and Cleo (id 3). EmployeeUNI contains only (id 2, unique_id 20). The output keeps all three names: Ana and Cleo have a missing unique_id; Bo has 20.

My solution

SQL 
SELECT eu.unique_id, e.name
FROM EmployeeUNI eu
RIGHT JOIN Employees e ON eu.id = e.id
pandas 
import pandas as pd
def replace_employee_id(employees: pd.DataFrame, employee_uni: pd.DataFrame) -> pd.DataFrame:
    df = employee_uni.merge(employees, on='id', how='right')
    return df[['unique_id','name']]

Why it works

The RIGHT JOIN keeps the Employees table on the right. The pandas right merge does the same, then both select only unique_id and name.
