Find the fraction of players active exactly one day after their own first login.

Pattern: First date / next-day retention

Example

Player 1 logs on Jan 1 and Jan 2; player 2 logs on Jan 1 and Jan 3 → fraction 0.50.

Study solution

SQL 
WITH first_login AS (
    SELECT player_id, MIN(event_date) AS first_day FROM Activity GROUP BY player_id
)
SELECT ROUND(AVG(CASE WHEN EXISTS (
    SELECT 1 FROM Activity a
    WHERE a.player_id = f.player_id AND a.event_date = DATE_ADD(f.first_day, INTERVAL 1 DAY)
) THEN 1 ELSE 0 END), 2) AS fraction
FROM first_login f;
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def gameplay_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    a = activity.assign(event_date=pd.to_datetime(activity['event_date']))
    first = a.groupby('player_id')['event_date'].transform('min')
    valid = a['event_date'].eq(first + pd.Timedelta(days=1))
    fraction = valid.groupby(a['player_id']).any().mean()
    return pd.DataFrame({'fraction': [round_half_up(fraction)]})

Why it works

Compare with the minimum date for each player, not merely the previous observed row. Group-level any prevents duplicate qualifying events from counting twice.

Notes

Count players who return the day after their first login, not any later two-day streak.
