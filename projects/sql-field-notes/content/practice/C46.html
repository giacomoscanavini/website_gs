1661 · Average processing time per machine

Pair each process start and end, then report the average duration per machine rounded to three decimals.

Pattern: CTEs / paired join / grouped mean

Illustrative example

Machine 0 runs a process from 1.0 to 2.5 and another from 3.0 to 5.5. The durations are 1.5 and 2.5, so its average processing_time is 2.000.

My solution

SQL 
WITH
    s AS (
        SELECT machine_id, process_id, timestamp
        FROM Activity
        WHERE activity_type = 'start'
    ),
    e AS (
        SELECT machine_id, process_id, timestamp
        FROM Activity
        WHERE activity_type = 'end'
    ),
    m AS (
        SELECT s.machine_id, s.process_id, e.timestamp - s.timestamp AS processing_time
        FROM s
        JOIN e ON s.machine_id = e.machine_id AND s.process_id = e.process_id
    )
SELECT machine_id, ROUND(SUM(processing_time)/COUNT(*), 3) AS processing_time
FROM m
GROUP BY machine_id
pandas 
from decimal import Decimal, ROUND_HALF_UP
import pandas as pd

def round_half_up(value, digits: int = 2):
    if pd.isna(value): return float('nan')
    return float(Decimal(str(value)).quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))

def get_average_time(activity: pd.DataFrame) -> pd.DataFrame:
    df_s = activity[activity.activity_type == 'start']
    df_e = activity[activity.activity_type == 'end']
    df = df_s.merge(df_e, on=['machine_id', 'process_id'], how='inner', suffixes=('_s', '_e'))
    df['processing_time'] = df['timestamp_e'] - df['timestamp_s']
    result = df.groupby('machine_id', as_index=False).agg(processing_time=('processing_time', 'mean'))
    result['processing_time'] = result['processing_time'].map(lambda x: round_half_up(x, 3))
    return result

Why it works

Both implementations split start and end events and join them on machine_id plus process_id. Subtracting the start timestamp from the end timestamp gives the duration. SQL uses SUM/COUNT and pandas uses mean to average those durations.

Each (machine_id, process_id) has one start and one end. Join on both keys.

pandas 
import pandas as pd

def get_average_time(activity: pd.DataFrame) -> pd.DataFrame:
    df_s = activity[activity.activity_type == 'start']
    df_e = activity[activity.activity_type == 'end']
    df = df_s.merge(df_e, on=['machine_id', 'process_id'], how='left', suffixes=('_s', '_e'))
    df['processing_time'] = df['timestamp_e'] - df['timestamp_s']
    df = df.drop(columns=['process_id', 'activity_type_s', 'activity_type_e', 'timestamp_s', 'timestamp_e'])

    return df.groupby(by='machine_id').mean().round(3).reset_index()
