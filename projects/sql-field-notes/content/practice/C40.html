1327 · Products with at least 100 February units

Sum each product’s February 2020 units and return qualifying product names.

Pattern: Date window / HAVING / join

Example

Product 1 has February orders of 60 and 50 units → 110 qualifies; an additional March order is ignored.

Study solution

SQL 
SELECT p.product_name, SUM(o.unit) AS unit FROM Orders o
JOIN Products p ON o.product_id = p.product_id
WHERE o.order_date >= '2020-02-01' AND o.order_date < '2020-03-01'
GROUP BY p.product_id, p.product_name HAVING SUM(o.unit) >= 100;
pandas 
import pandas as pd

def list_products(products: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
    dates = pd.to_datetime(orders['order_date'])
    feb = orders.loc[dates.ge('2020-02-01') & dates.lt('2020-03-01')]
    g = feb.groupby('product_id', as_index=False).agg(unit=('unit', 'sum'))
    return g.loc[g['unit'].ge(100)].merge(products, on='product_id', how='inner')[['product_name', 'unit']]

Why it works

Filter dates before summing. Group by product ID rather than name so different products sharing a name do not merge.

Notes

Count orders within February 2020. Sales in other months do not disqualify a product.

pandas 
import pandas as pd
def list_products(products: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
    orders = orders.assign(order_date=pd.to_datetime(orders['order_date']))
    orders =   orders[(orders.order_date >= '2020-02-01') & (orders.order_date < '2020-03-01')]
    df =   orders.groupby(by='product_id').agg(
        unit = ('unit', 'sum')
    ).reset_index()
    df =   df[df.unit >= 100]
    df =   df.merge(products, on='product_id', how='left')
    return df[['product_name', 'unit']]
