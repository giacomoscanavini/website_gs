620 · Not boring movies

Keep odd-ID movies with a non-boring description, sorted by rating descending.

Pattern: Filtering / sorting

Example

ID 1 exciting/8.0 and ID 3 exciting/9.0 survive; output is 3 then 1.

Study solution

SQL 
SELECT id, movie, description, rating FROM Cinema
WHERE id % 2 = 1 AND description <> 'boring' ORDER BY rating DESC;
pandas 
import pandas as pd

def not_boring_movies(cinema: pd.DataFrame) -> pd.DataFrame:
    mask = cinema['id'].mod(2).eq(1) & cinema['description'].notna() & cinema['description'].ne('boring')
    return cinema.loc[mask].sort_values('rating', ascending=False)

Why it works

Use modulo for odd IDs and an explicit sort for output order. Single quotes are the portable SQL string syntax.
