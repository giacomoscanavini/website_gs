180 · Consecutive Numbers

Find values appearing in at least three consecutive rows when Logs is ordered by id.

Pattern: Ordered windows / shifts

Example

Ordered num values [1,1,1,2,2,3] → ConsecutiveNums 1.

Study solution

SQL 
WITH ordered AS (
    SELECT num, LEAD(num, 1) OVER (ORDER BY id) AS next_num,
           LEAD(num, 2) OVER (ORDER BY id) AS next_next_num FROM Logs
)
SELECT DISTINCT num AS ConsecutiveNums FROM ordered
WHERE num = next_num AND num = next_next_num;
pandas 
import pandas as pd

def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    ordered = logs.sort_values('id')
    n = ordered['num']
    mask = n.eq(n.shift(-1)) & n.eq(n.shift(-2))
    return ordered.loc[mask, ['num']].drop_duplicates().rename(columns={'num': 'ConsecutiveNums'})

Why it works

Sort explicitly and compare each value with its next two neighbors. Exact equality avoids relying on floating-point rolling variance being exactly zero.

Notes

Consecutive means neighboring rows in id order. Numeric adjacency would also require id + 1 and id + 2 checks.

import pandas as pd

def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    logs = logs.sort_values('id')
    numbers = logs['num']
    repeated = numbers.eq(numbers.shift(1)) & numbers.eq(numbers.shift(2))
    return pd.DataFrame({'ConsecutiveNums': logs.loc[repeated, 'num'].unique()})

import pandas as pd

def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    logs['var'] = logs['num'].rolling(window=3).var()
    return pd.DataFrame({'ConsecutiveNums': logs[logs['var']==0]['num'].unique()})
