3421 · Find students who improved

Compare first and latest scores within each student–subject pair, keeping increases.

My submission

MySQL 
# Write your MySQL query statement below
WITH Comparison AS (
    SELECT 
        student_id,
        subject,
        NTH_VALUE(score, 1) OVER (
            PARTITION BY student_id, subject
            ORDER BY exam_date ASC
        ) AS first_score,
        NTH_VALUE(score, 1) OVER (
            PARTITION BY student_id, subject
            ORDER BY exam_date DESC
        ) AS latest_score
    FROM Scores
)

SELECT DISTINCT student_id, subject, first_score, latest_score
FROM Comparison
WHERE first_score < latest_score
pandas 
import pandas as pd

def find_students_who_improved(scores: pd.DataFrame) -> pd.DataFrame:
    def custom_func(x):
        first_date = x['exam_date'].argmin()
        last_date = x['exam_date'].argmax()

        latest_score = x['score'].iloc[last_date]
        first_score = x['score'].iloc[first_date]

        return pd.Series({
            'improved': latest_score > first_score,
            'first_score': first_score,
            'latest_score': latest_score,
        })

    df = scores.groupby(by=['student_id', 'subject']).apply(custom_func).reset_index()

    return df[df.improved == True][['student_id', 'subject', 'first_score', 'latest_score']]

How the submitted approach works

The SQL uses NTH_VALUE in ascending and descending exam-date order. The pandas function uses argmin/argmax to locate endpoint scores inside each group.

Implementation note. No tie-break is specified for duplicate exam dates. Grouped first/last alternatives also have different behavior when endpoint scores are missing.
