BFGS, L-BFGS, and line search

BFGS estimates curvature from changes in parameters and gradients. L-BFGS limits the stored history, while line search selects a step that supports both descent and the next curvature estimate.

Infer curvature rather than compute the full Hessian

Newton’s method uses a local Hessian to determine a direction. BFGS instead observes how the gradient changes when the parameters move. Define

sk=θk+1−θk,yk=gk+1−gk.s_k=\theta_{k+1}-\theta_k,\qquad y_k=g_{k+1}-g_k.

For a local quadratic, yk=Hsky_k=Hs_k . A quasi-Newton approximation tries to preserve this relationship. If BB denotes a Hessian approximation, the secant condition is Bk+1sk=ykB_{k+1}s_k=y_k .

In the update below, HkH_k denotes an inverse-Hessian approximation, not the exact Hessian used in Newton’s method.

The inverse update and curvature condition

With ρk=1/(yk⊤sk)\rho_k=1/(y_k^\top s_k) ,

Hk+1=(I−ρkskyk⊤)Hk(I−ρkyksk⊤)+ρksksk⊤.H_{k+1}=(I-\rho_ks_ky_k^\top)H_k(I-\rho_ky_ks_k^\top)+\rho_ks_ks_k^\top.

The direction is pk=−Hkgkp_k=-H_kg_k . The update is constructed to incorporate the newest observed curvature information while retaining a useful approximation from earlier steps.

The condition yk⊤sk>0y_k^\top s_k>0 is central to preserving positive definiteness when the previous approximation is positive definite. Appropriate line-search conditions help obtain this property. The curvature update and step-selection rule work together to maintain a usable search direction.

Why line search evaluates the objective repeatedly

Given a direction pkp_k, define φ(α)=J(θk+αpk)\varphi(\alpha)=J(\theta_k+\alpha p_k). A line search seeks a useful positive α\alpha. The Armijo sufficient-decrease condition is

J(θk+αpk)≤J(θk)+c1αgk⊤pk.J(\theta_k+\alpha p_k)\le J(\theta_k)+c_1\alpha g_k^\top p_k.

Wolfe-type conditions add information about the directional derivative after the step. The purpose is not only to lower the loss, but also to make subsequent curvature information useful.

Each trial can require another function or gradient evaluation. One accepted iteration is consequently not directly comparable to an SGD step. Compare data passes or wall-clock work as well as iteration counts.

Limited memory changes the storage cost

Full BFGS stores an approximately d×dd\times d matrix, costing O(d2)O(d^2) memory. L-BFGS retains only the most recent mm pairs (sk,yk)(s_k,y_k) and reconstructs the inverse-Hessian action implicitly. Its history storage is O(md)O(md) .

Limited memory makes the method more practical, but it does not make line-search reevaluation or high-quality gradient information free. For very large stochastic networks, a cheaper noisy first-order update can make more useful progress per unit of computation.

Why stochastic gradients are difficult here

If gkg_k and gk+1g_{k+1} use different mini-batches, their difference contains both parameter-induced curvature information and changes in the sampled observations. The secant pair can become a noisy account of the local surface. Random augmentation or dropout also changes the evaluated function unless controlled appropriately.

L-BFGS is consequently better suited to objectives that can be reevaluated consistently, such as smaller smooth full-batch problems, deterministic fine-tuning, and scientific optimization. Large stochastic training runs often favor cheaper first-order updates because reliable curvature information is harder to obtain.

Closures in PyTorch

An L-BFGS step can evaluate several trial parameter values. In PyTorch, a closure supplies a fresh forward pass, loss, and gradient at each trial. The linked sequence-prediction example demonstrates this mechanism with LSTM cells and plots its predictions on a synthetic sequence task.

The closure must evaluate a consistent objective. The cost of these repeated evaluations matters as much as the number of accepted optimizer steps.
