The recursive definition

For a network with LL transformations, set a[0]=xa^{[0]}=x and compute

z[ℓ]=W[ℓ]a[ℓ−1]+b[ℓ],a[ℓ]=ϕ[ℓ](z[ℓ]).z^{[\ell]}=W^{[\ell]}a^{[\ell-1]}+b^{[\ell]},\qquad a^{[\ell]}=\phi^{[\ell]}(z^{[\ell]}).

The output is the last activation. The notation separates pre-activation zz , activation aa , and parameters W,bW,b . Maintaining that separation is essential when deriving the backward pass.

The example below preserves the numerical values from the supplied guide. It is a single observation, not a fitted dataset or a performance demonstration.

Step 1: compute the hidden pre-activations

Take

x=[12],W[1]=[0.5−0.20.30.8],b[1]=[0.1−0.1].x=\begin{bmatrix}1\\2\end{bmatrix},\quad W^{[1]}=\begin{bmatrix}0.5&-0.2\\0.3&0.8\end{bmatrix},\quad b^{[1]}=\begin{bmatrix}0.1\\-0.1\end{bmatrix}.

Each row of the weight matrix produces one hidden unit:

z1[1]=0.5(1)−0.2(2)+0.1=0.2,z^{[1]}_1=0.5(1)-0.2(2)+0.1=0.2,
z2[1]=0.3(1)+0.8(2)−0.1=1.8.z^{[1]}_2=0.3(1)+0.8(2)-0.1=1.8.

There are two input coordinates and two hidden coordinates, but their meanings differ. The hidden values are learned combinations of inputs rather than additional observations.

Step 2: apply the hidden activation

Both pre-activations are positive, so ReLU leaves them unchanged:

z[1]=[0.21.8],a[1]=[0.21.8].z^{[1]}=\begin{bmatrix}0.2\\1.8\end{bmatrix},\qquad a^{[1]}=\begin{bmatrix}0.2\\1.8\end{bmatrix}.

ReLU happens to be the identity on these two values. The network is still globally nonlinear because another input could make one of those values negative and change the active path. A single forward pass explores one region of the function.

Step 3: compute the output logit

Use

W[2]=[0.7−0.5],b[2]=0.2.W^{[2]}=\begin{bmatrix}0.7&-0.5\end{bmatrix},\qquad b^{[2]}=0.2.

Then

z[2]=0.7(0.2)−0.5(1.8)+0.2=−0.56.z^{[2]}=0.7(0.2)-0.5(1.8)+0.2=-0.56.

The positive contribution of the first hidden unit is 0.140.14 , and the negative contribution of the second is −0.9-0.9 . Adding the output bias gives a negative logit. The sign is meaningful for a binary classifier: after sigmoid, a negative logit corresponds to a probability below one half.

Step 4: map to a probability and evaluate the loss

ŷ=σ(−0.56)≈0.363547.\hat y=\sigma(-0.56)\approx0.363547.

For target y=1y=1 , the binary cross-entropy loss reduces to

L=−log(ŷ)≈1.01185.L=-\log(\hat y)\approx1.01185.

The PDF rounds this to approximately 1.0118. This is a penalty for assigning insufficient probability to the true class, not a classification accuracy. If we thresholded at 0.50.5 , the example would be classified as zero, but the loss uses the full confidence value.

Step by step Expand the entire numerical forward calculation

Setting. Use the exact parameters shown above, one example x=(1,2)⊤x=(1,2)^\top , and target y=1y=1 . Decimal approximations are introduced only after the affine calculations.

1 · Expand the first matrix multiplication

The first row gives 0.5⋅1+(−0.2)⋅2=0.5−0.4=0.10.5\cdot1+(-0.2)\cdot2=0.5-0.4=0.1 . Its bias makes z1=0.1+0.1=0.2z_1=0.1+0.1=0.2 . The second row gives 0.3⋅1+0.8⋅2=0.3+1.6=1.90.3\cdot1+0.8\cdot2=0.3+1.6=1.9 , then z2=1.9−0.1=1.8z_2=1.9-0.1=1.8 .

2 · Evaluate ReLU separately for each coordinate

a1=max(0,0.2)=0.2,a2=max(0,1.8)=1.8.a_1=\max(0,0.2)=0.2,\qquad a_2=\max(0,1.8)=1.8.

These are the inputs to the next affine layer; the original xx is not multiplied by the output weights directly.

3 · Form the output logit

z=0.7⋅0.2+(−0.5)⋅1.8+0.2=0.14−0.90+0.20=−0.56.z=0.7\cdot0.2+(-0.5)\cdot1.8+0.2=0.14-0.90+0.20=-0.56.

A logit is a real-valued score, not yet a probability.

4 · Compute the binary probability

p=11+e−z=11+e0.56.p=\frac1{1+e^{-z}}=\frac1{1+e^{0.56}}.

With e0.56≈1.7506725003e^{0.56}\approx1.7506725003 , the denominator is 2.75067250032.7506725003 and

p≈0.3635474597.p\approx0.3635474597.

The complementary class probability is 1−p≈0.63645254031-p\approx0.6364525403 .

5 · Substitute the target into both loss terms

L=−[1logp+(1−1)log(1−p)]=−logp.L=-[1\log p+(1-1)\log(1-p)]=-\log p.

Since p=(1+e0.56)−1p=(1+e^{0.56})^{-1} ,

L=log(1+e0.56)≈1.0118454273.L=\log(1+e^{0.56})\approx1.0118454273.

This logarithmic form avoids rounding the probability before computing the loss. Both forms are algebraically equal.

6 · Check the output’s odds

From p/(1−p)=ezp/(1-p)=e^z , the odds are e−0.56≈0.5712091e^{-0.56}\approx0.5712091 . The log odds are therefore log[p/(1−p)]=−0.56\log[p/(1-p)]=-0.56 , recovering the original logit. A threshold of p=1/2p=1/2 corresponds exactly to z=0z=0 , but thresholding is not part of the differentiable loss calculation.

Reproduce the full forward and backward pass Local worked example · Python / PyTorch

A small authored companion reproducing the exact network in the supplied guide. Every parameter gradient is checked against the hand calculation, followed by one update. Run locally; Python is not executed by this webpage.

worked_backprop.py 
"""Reproduce the supplied 2 → 2 → 1 forward and backward calculation"""

import torch
import torch.nn.functional as F


def main() -> None:
    dtype = torch.float64
    x = torch.tensor([1.0, 2.0], dtype=dtype)
    y = torch.tensor(1.0, dtype=dtype)
    w1 = torch.tensor([[0.5, -0.2], [0.3, 0.8]], dtype=dtype, requires_grad=True)
    b1 = torch.tensor([0.1, -0.1], dtype=dtype, requires_grad=True)
    w2 = torch.tensor([0.7, -0.5], dtype=dtype, requires_grad=True)
    b2 = torch.tensor(0.2, dtype=dtype, requires_grad=True)

    z1 = w1 @ x + b1
    hidden = z1.relu()
    logit = w2 @ hidden + b2
    loss = F.binary_cross_entropy_with_logits(logit, y)
    loss.backward()

    # The hand calculation uses the source's single-observation convention
    with torch.no_grad():
        delta2 = logit.sigmoid() - y
        delta1 = w2 * delta2 * (z1 > 0)
        expected = [torch.outer(delta1, x), delta1, delta2 * hidden, delta2]
        parameters = [w1, b1, w2, b2]
        for parameter, gradient in zip(parameters, expected):
            torch.testing.assert_close(parameter.grad, gradient, rtol=1e-12, atol=1e-12)

        print(f"Hidden activations: {hidden.tolist()}")
        print(f"Logit: {logit.item():.6f}; probability: {logit.sigmoid().item():.6f}")
        print(f"Loss before update: {loss.item():.6f}")
        for name, parameter in zip(["W1", "b1", "W2", "b2"], parameters):
            print(f"Gradient {name}: {parameter.grad.tolist()}")
            parameter.add_(parameter.grad, alpha=-0.1)

        next_logit = w2 @ (w1 @ x + b1).relu() + b2
        next_loss = F.binary_cross_entropy_with_logits(next_logit, y)
        assert next_loss < loss, "The illustrated update should reduce this example's loss"
        print(f"Updated W1: {w1.tolist()}")
        print(f"Updated W2: {w2.tolist()}")
        print(f"Loss after update: {next_loss.item():.6f}")
        print("All four autograd gradients match the hand derivation")


if __name__ == "__main__":
    main()

Check your understanding Which quantities in this example are learned, and which are recomputed?

Weights and biases are learned. Pre-activations, hidden activations, logits, probabilities, and the loss are recomputed from the current parameters for each input. A forward pass uses the parameters but does not update them.
