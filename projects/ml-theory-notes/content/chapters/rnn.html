Recurrent networks and backpropagation through time

A recurrent network reuses a state-transition function across a sequence. Backpropagation through time differentiates this unrolled computation and accumulates gradients for the shared parameters.

A state transition reused across time

A vanilla RNN introduces a hidden state hth_t :

at=Wxxt+Whht−1+bh,ht=ϕ(at),yt=Wyht+by.a_t=W_xx_t+W_hh_{t-1}+b_h,\qquad h_t=\phi(a_t),\qquad y_t=W_yh_t+b_y.

The same parameters are reused at each step. Unrolling the network makes a long computation graph but does not create a separate set of recurrent weights for every time position. Parameter sharing is part of the sequential inductive bias.

The hidden state is a task-shaped summary of earlier inputs. It is not guaranteed to store a human-readable record, nor to preserve every detail. Training rewards the aspects of history that help reduce the chosen loss.

Sequence-to-output relationships

A recurrent model can produce one output for an entire sequence, aligned outputs at each step, or an output sequence of a different length through an encoder–decoder. These tasks share the recurrent mechanism but differ in output structure and loss placement.

If a loss is applied at each time step, the shared parameters receive contributions through many paths. If a loss is applied only at the end, earlier inputs must influence the final state sufficiently to receive useful credit.

Work through the scalar example

Use h0=0h_0=0, wx=0.8w_x=0.8, wh=0.6w_h=0.6, b=0b=0, and ϕ=tanh\phi=\tanh, with inputs 11, 0.50.5, and −0.5-0.5. The successive states are

h1=tanh(0.8)≈0.664,h_1=\tanh(0.8)\approx0.664,
h2=tanh(0.8(0.5)+0.6h1)≈0.663,h_2=\tanh(0.8(0.5)+0.6h_1)\approx0.663,
h3=tanh(0.8(−0.5)+0.6h2)≈−0.002.h_3=\tanh(0.8(-0.5)+0.6h_2)\approx-0.002.

The final state depends on all three inputs through the recursion. These fixed illustrative weights demonstrate a stateful computation; they do not represent a trained model evaluation.

The displayed values are rounded. Retain full precision when comparing derivatives.

2 · Calculate the one-step derivatives

With respect to the previous state, the derivative is

jt=dhtdht−1=0.6(1−ht2).j_t=\frac{dh_t}{dh_{t-1}}=0.6(1-h_t^2).

Thus j2≈0.3361j_2\approx0.3361 and j3≈0.6000j_3\approx0.6000 . The sensitivity of h3h_3 to h1h_1 is j3j2≈0.2017j_3j_2\approx0.2017 , not either factor alone.

3 · Include the input-to-state derivative

dh1dx1=0.8(1−h12)≈0.4472.\frac{dh_1}{dx_1}=0.8(1-h_1^2)\approx0.4472.

Combining the three links,

dh3dx1=j3j20.8(1−h12)≈0.0902.\frac{dh_3}{dx_1}=j_3j_2\,0.8(1-h_1^2)\approx0.0902.

This is a concrete demonstration that the third state depends on the first input even though the last pre-activation nearly cancels to zero.

4 · Separate local cancellation from loss of memory

A state value near zero is not itself proof that an earlier input has no influence. Values measure the current output; derivatives measure sensitivity to perturbations. Conversely, a nonzero hidden state is not proof that sensitivity to distant inputs remains strong.

BPTT is ordinary backpropagation on the unrolled graph

For a loss depending on hTh_T , an earlier derivative contains

gk⊤=gT⊤JTJT−1⋯Jk+1,Jj=∂hj∂hj−1,g_k^\top=g_T^\top J_TJ_{T-1}\cdots J_{k+1},\qquad J_j=\frac{\partial h_j}{\partial h_{j-1}},

where gt=∇htLg_t=\nabla_{h_t}L is a column gradient and the displayed transposes make the row-sensitivity convention explicit. The one-step Jacobian is

∂hj∂hj−1=diag(ϕ′(aj))Wh.\frac{\partial h_j}{\partial h_{j-1}}=\operatorname{diag}(\phi'(a_j))W_h.

The factors are written in their actual order because state-transition Jacobians need not commute. The essential mechanism is repeated multiplication by state-transition Jacobians. Gradients for shared parameters accumulate contributions from every place those parameters were used.

Step by step Derive BPTT, Jacobian order, and shared-parameter gradients

Setting. Let at=Wxxt+Whht−1+ba_t=W_xx_t+W_hh_{t-1}+b , ht=ϕ(at)h_t=\phi(a_t) , and L=∑t=1Tℓt(ht)L=\sum_{t=1}^T\ell_t(h_t) . Treat h0h_0 as fixed. All gradients below are column vectors . Let Dt=diag(ϕ′(at))D_t=\operatorname{diag}(\phi'(a_t)) and ut=∇htℓtu_t=\nabla_{h_t}\ell_t be the direct loss contribution at step tt .

1 · Derive the one-step state Jacobian

The affine derivative is ∂at/∂ht−1=Wh\partial a_t/\partial h_{t-1}=W_h . The elementwise activation derivative is ∂ht/∂at=Dt\partial h_t/\partial a_t=D_t . Applying the chain rule gives

Jt=∂ht∂ht−1=DtWh.J_t=\frac{\partial h_t}{\partial h_{t-1}}=D_tW_h.

Matrix order matters: first WhW_h acts on a perturbation, then DtD_t scales its output coordinates.

2 · Add the direct and future loss paths

The total gradient gt=∇htLg_t=\nabla_{h_t}L receives the direct contribution utu_t and the contribution through ht+1h_{t+1} :

gt=ut+Jt+1⊤gt+1,gT=uT.g_t=u_t+J_{t+1}^\top g_{t+1},\qquad g_T=u_T.

This is reverse-mode differentiation on a graph with two outgoing routes from hth_t .

3 · Expand two steps to fix the product order

gk=uk+Jk+1⊤uk+1+Jk+1⊤Jk+2⊤gk+2.g_k=u_k+J_{k+1}^\top u_{k+1}+J_{k+1}^\top J_{k+2}^\top g_{k+2}.

Continuing gives, for a loss only at the final step ,

gk=Jk+1⊤Jk+2⊤⋯JT⊤gT.g_k=J_{k+1}^\top J_{k+2}^\top\cdots J_T^\top g_T.

Equivalently, using row gradients gives gk⊤=gT⊤JTJT−1⋯Jk+1g_k^\top=g_T^\top J_TJ_{T-1}\cdots J_{k+1} . An ascending unqualified product after a row gradient would be ambiguous or wrong because these Jacobians do not generally commute.

4 · Move from state gradients to pre-activation gradients

Define δt=∇atL=Dtgt\delta_t=\nabla_{a_t}L=D_tg_t . Since Jt+1⊤=Wh⊤Dt+1J_{t+1}^\top=W_h^\top D_{t+1} ,

δt=(ut+Wh⊤δt+1)⊙ϕ′(at),δT+1=0.\delta_t=(u_t+W_h^\top\delta_{t+1})\odot\phi'(a_t),\qquad\delta_{T+1}=0.

The recurrence includes every direct loss and every future contribution once.

5 · Sum every occurrence of each shared parameter

For entry (Wh)ij(W_h)_{ij} at time tt , ∂at,i/∂(Wh)ij=ht−1,j\partial a_{t,i}/\partial(W_h)_{ij}=h_{t-1,j} . Because the same parameter appears at all times, the chain rule sums these local contributions:

∇WhL=∑t=1Tδtht−1⊤,∇WxL=∑t=1Tδtxt⊤,∇bL=∑t=1Tδt.\nabla_{W_h}L=\sum_{t=1}^T\delta_th_{t-1}^\top,\qquad \nabla_{W_x}L=\sum_{t=1}^T\delta_tx_t^\top,\qquad \nabla_bL=\sum_{t=1}^T\delta_t.

Future dependence of ht−1h_{t-1} is already handled through the reverse recurrence; adding it separately again would double count.

6 · Interpret truncation

Detaching a boundary hidden state removes the derivative paths through earlier chunks. Its numerical value can still carry history forward, but losses in the current chunk no longer update parameters through those earlier operations. Truncated BPTT is therefore an approximation to the full-sequence gradient, not merely a different memory allocation.

Vanishing and explosion

If the effective transformations repeatedly contract, distant-state sensitivity becomes small. If they repeatedly amplify, it can become enormous. Tanh’s derivative is at most one and becomes small in saturated regions, adding another contraction mechanism.

Clipping can limit explosions. Truncated BPTT limits the length of the gradient graph for long streams. Gated models introduce different state paths. Attention offers direct interactions without requiring every dependency to traverse all intermediate recurrent transitions.

Vanilla recurrence remains useful as a baseline and for tasks where dependencies are short or a streaming state is appropriate. Long-range dependencies require particular attention to the gradient path and the information retained by the state.

Sequence classification and tagging

Character-level name classification uses a sequence to produce one class prediction. Part-of-speech tagging instead produces an output for each token. The examples below show how state updates and loss placement support these different mappings.

For either task, specify how the hidden state is initialized, whether it resets between independent examples, where the loss is applied, and whether future context is available. These choices determine the prediction problem the network actually solves.

Check your understanding Does an RNN’s hidden state mean it can remember arbitrarily long histories?

No. The state is a learned summary, and useful memory depends on the dynamics and training. Long derivative paths can vanish or explode. A technically available input history is not the same as information that the fitted state preserves.
