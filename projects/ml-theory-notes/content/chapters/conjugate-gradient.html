Begin with a linear system

Classical Conjugate Gradient solves Ax=bAx=b for symmetric positive-definite AA . This is equivalent to minimizing

f(x)=12x⊤Ax−b⊤x,f(x)=\frac12x^\top Ax-b^\top x,

because ∇f(x)=Ax−b\nabla f(x)=Ax-b . The residual r=b−Axr=b-Ax is therefore the negative gradient.

Steepest descent chooses each direction from the current slope. In an elongated quadratic, that can undo aspects of previous progress. CG chooses directions that are conjugate under the metric defined by AA :

pi⊤Apj=0(i≠j).p_i^\top A p_j=0\quad(i\ne j).

This is different from ordinary Euclidean orthogonality pi⊤pj=0p_i^\top p_j=0 . For the quadratic, minimizing along a new conjugate direction does not disturb the optimum already established along previous conjugate directions.

The recursion

Set r0=b−Ax0r_0=b-Ax_0 and p0=r0p_0=r_0 . Then compute

αk=rk⊤rkpk⊤Apk,xk+1=xk+αkpk,\alpha_k=\frac{r_k^\top r_k}{p_k^\top Ap_k},\qquad x_{k+1}=x_k+\alpha_kp_k,
rk+1=rk−αkApk,βk=rk+1⊤rk+1rk⊤rk,r_{k+1}=r_k-\alpha_kAp_k,\qquad \beta_k=\frac{r_{k+1}^\top r_{k+1}}{r_k^\top r_k},
pk+1=rk+1+βkpk.p_{k+1}=r_{k+1}+\beta_kp_k.

The expensive operation is an action of AA on a vector, not an explicit matrix inverse. In larger systems, that distinction can make CG attractive when a matrix–vector product is available cheaply.

Step by step Derive CG’s step length and conjugate direction

Setting. A≻0A\succ0 is symmetric, calculations use exact arithmetic, and the initial point is fixed. Let rk=b−Axkr_k=b-Ax_k , so ∇f(xk)=−rk\nabla f(x_k)=-r_k .

1 · Minimize exactly along an arbitrary direction

For x(α)=xk+αpkx(\alpha)=x_k+\alpha p_k ,

ddαf(xk+αpk)=pk⊤(Axk−b)+αpk⊤Apk=−pk⊤rk+αpk⊤Apk.\frac{d}{d\alpha}f(x_k+\alpha p_k) =p_k^\top(Ax_k-b)+\alpha p_k^\top Ap_k =-p_k^\top r_k+\alpha p_k^\top Ap_k.

Setting this to zero yields αk=pk⊤rk/(pk⊤Apk)\alpha_k=p_k^\top r_k/(p_k^\top Ap_k) .

2 · Update the residual by substitution

rk+1=b−A(xk+αkpk)=rk−αkApk.r_{k+1}=b-A(x_k+\alpha_kp_k)=r_k-\alpha_kAp_k.

Taking its inner product with pkp_k and using step 1 gives pk⊤rk+1=0p_k^\top r_{k+1}=0 . Exact line minimization makes the new residual orthogonal to the direction just used.

3 · Explain why earlier orthogonality is retained

Suppose previous directions are mutually AA -conjugate and rkr_k is orthogonal to them. For j<kj<k ,

pj⊤rk+1=pj⊤rk−αkpj⊤Apk=0−0=0.p_j^\top r_{k+1}=p_j^\top r_k-\alpha_k p_j^\top Ap_k=0-0=0.

Thus the next residual is orthogonal to all directions used so far. The property starts at k=0k=0 after the first exact line search and is preserved by conjugate updates.

4 · Simplify the numerator

The direction has the form pk=rk+βk−1pk−1p_k=r_k+\beta_{k-1}p_{k-1} . Because pk−1⊤rk=0p_{k-1}^\top r_k=0 ,

pk⊤rk=rk⊤rk.p_k^\top r_k=r_k^\top r_k.

This recovers the usual αk=(rk⊤rk)/(pk⊤Apk)\alpha_k=(r_k^\top r_k)/(p_k^\top Ap_k) .

5 · Enforce conjugacy for the next direction

Set pk+1=rk+1+βkpkp_{k+1}=r_{k+1}+\beta_kp_k . Requiring pk+1⊤Apk=0p_{k+1}^\top Ap_k=0 gives

βk=−rk+1⊤Apkpk⊤Apk.\beta_k=-\frac{r_{k+1}^\top Ap_k}{p_k^\top Ap_k}.

From step 2, Apk=(rk−rk+1)/αkAp_k=(r_k-r_{k+1})/\alpha_k . Also rk=pk−βk−1pk−1r_k=p_k-\beta_{k-1}p_{k-1} lies in the span of directions to which rk+1r_{k+1} is orthogonal. Hence rk+1⊤rk=0r_{k+1}^\top r_k=0 and

rk+1⊤Apk=−∥rk+1∥2αk.r_{k+1}^\top Ap_k=-\frac{\|r_{k+1}\|^2}{\alpha_k}.

Substitute αkpk⊤Apk=∥rk∥2\alpha_kp_k^\top Ap_k=\|r_k\|^2 to obtain βk=∥rk+1∥2/∥rk∥2\beta_k=\|r_{k+1}\|^2/\|r_k\|^2 .

6 · Check conjugacy with all older directions

For j<kj<k , Apj=(rj−rj+1)/αjAp_j=(r_j-r_{j+1})/\alpha_j is in the span of earlier search directions. The new residual is orthogonal to that span. Therefore rk+1⊤Apj=0r_{k+1}^\top Ap_j=0 , and the βkpk\beta_kp_k term is also AA -orthogonal to pjp_j . This completes the induction behind the recursion.

7 · Understand finite termination

Nonzero mutually AA -conjugate directions are linearly independent: multiplying a zero linear combination by each pj⊤Ap_j^\top A forces its coefficient to zero. There can be at most dd such directions in ℝd\mathbb R^d . After minimizing along a full basis, the residual is orthogonal to all of ℝd\mathbb R^d , so it is zero. Roundoff destroys exact orthogonality; the finite-step statement is not an unqualified floating-point promise.

Complete the second step

The source states that a second line minimization reaches the exact solution. Expanding that final arithmetic,

Ap1=[−11/811/16],α1=5/1655/64=411.Ap_1=\begin{bmatrix}-11/8\\11/16\end{bmatrix},\qquad \alpha_1=\frac{5/16}{55/64}=\frac4{11}.

Nonlinear CG is a different extension

For a nonquadratic neural objective, nonlinear CG uses

pk+1=−gk+1+βkpkp_{k+1}=-g_{k+1}+\beta_kp_k

with a line search to choose the step. The PDF describes Fletcher–Reeves,

βkFR=gk+1⊤gk+1gk⊤gk,\beta_k^{\mathrm{FR}}=\frac{g_{k+1}^\top g_{k+1}}{g_k^\top g_k},

and Polak–Ribiere,

βkPR=gk+1⊤(gk+1−gk)gk⊤gk.\beta_k^{\mathrm{PR}}=\frac{g_{k+1}^\top(g_{k+1}-g_k)}{g_k^\top g_k}.

Exact conjugacy no longer persists automatically, and restarts can be important. Mini-batch noise can further disrupt line-search and history assumptions. “CG is fast on a quadratic” does not establish that it is a superior default for large stochastic networks.

Solve the guide’s two-dimensional CG example Local worked example · Python / PyTorch

An authored implementation for the source’s symmetric positive-definite system, with the second step written out and checked against a direct solve. This is not a general nonlinear optimizer. Run locally; Python is not executed by this webpage.

cg_quadratic.py 
"""Classical CG on the source's symmetric positive-definite two-dimensional system"""

import torch


def conjugate_gradient(a: torch.Tensor, b: torch.Tensor, tolerance: float = 1e-12) -> torch.Tensor:
    if a.ndim != 2 or a.shape != (b.numel(), b.numel()) or b.ndim != 1:
        raise ValueError("Expected a square matrix and a matching one-dimensional right-hand side")
    if tolerance <= 0 or not a.is_floating_point() or a.dtype != b.dtype:
        raise ValueError("Use a positive tolerance and matching floating-point dtypes")
    if not torch.allclose(a, a.T):
        raise ValueError("Classical CG requires a symmetric matrix")
    if not torch.all(torch.linalg.eigvalsh(a) > 0):
        raise ValueError("This educational implementation requires positive definiteness")

    x = torch.zeros_like(b)
    residual = b - a @ x
    direction = residual.clone()
    squared_norm = residual @ residual
    if squared_norm.sqrt() <= tolerance:
        return x

    for step in range(b.numel()):
        action = a @ direction
        denominator = direction @ action
        if denominator <= 0:
            raise ArithmeticError("Encountered nonpositive curvature")
        alpha = squared_norm / denominator
        x = x + alpha * direction
        residual = residual - alpha * action
        next_squared_norm = residual @ residual
        print(f"Step {step + 1}: alpha={alpha.item():.8f}, x={x.tolist()}, residual={residual.tolist()}")
        if next_squared_norm.sqrt() <= tolerance:
            return x
        beta = next_squared_norm / squared_norm
        direction = residual + beta * direction
        squared_norm = next_squared_norm
    return x


def main() -> None:
    a = torch.tensor([[4.0, 1.0], [1.0, 3.0]], dtype=torch.float64)
    b = torch.tensor([1.0, 2.0], dtype=torch.float64)
    result = conjugate_gradient(a, b)
    torch.testing.assert_close(result, torch.linalg.solve(a, b), atol=1e-12, rtol=1e-12)
    torch.testing.assert_close(a @ result, b, atol=1e-12, rtol=1e-12)
    print("CG agrees with the direct solve: [1/11, 7/11]")
    print("This small deterministic example is not a general nonlinear training optimizer")


if __name__ == "__main__":
    main()

Check your understanding What does conjugate mean, and where does the finite-step guarantee apply?

Directions are A-conjugate when pᵢᵀApⱼ=0 for i≠j. Classical CG solves a d-dimensional symmetric positive-definite quadratic in at most d steps in exact arithmetic. That guarantee does not transfer to noisy, nonquadratic neural-network training.
