Neurons, layers, and model capacity

Dense networks compose affine transformations and nonlinear activations. Their dimensions determine the parameter count and constrain the representations they can learn.

Start with one neuron

A neuron computes a pre-activation and then transforms it:

z=w⊤x+b,a=ϕ(z).z=w^\top x+b,\qquad a=\phi(z).

The weights set the contribution of each input. The bias shifts the operating region. The activation ϕ\phi determines how the weighted signal is transformed. These are three different roles; a neuron is not merely an “on/off switch.” ReLU, for example, outputs the actual positive magnitude, not the value one.

For example, take x=(2,−1,3)⊤x=(2,-1,3)^\top, w=(0.5,0.7,−0.2)⊤w=(0.5,0.7,-0.2)^\top, and b=0.3b=0.3. Thus

z=0.5(2)+0.7(−1)−0.2(3)+0.3=0.z=0.5(2)+0.7(-1)-0.2(3)+0.3=0.

ReLU returns zero for this pre-activation. At a pre-activation of two, it returns two: the positive branch preserves magnitude rather than producing a binary on/off value.

Collect neurons into a matrix

With nn inputs and mm output units, a dense layer has W∈ℝm×nW\in\mathbb R^{m\times n} and b∈ℝmb\in\mathbb R^m :

z=Wx+b,a=ϕ(z).z=Wx+b,\qquad a=\phi(z).

Each row of WW contains one neuron’s incoming weights. With a single example written as a column vector, the layer computes an affine map. PyTorch normally stores a batch with examples in rows, so the corresponding implementation is XW⊤+bXW^\top+b. The mathematical map is the same; the storage convention differs.

For 784→128→64→10784\to128\to64\to10 , the weight shapes are 128×784128\times784 , 64×12864\times128 , and 10×6410\times64 . The intermediate activation widths are 128 and 64; the final width is ten. A batch dimension adds examples, not new model parameters .

Parameter count

A dense layer with a bias has

nparameters=ninnout+nout.n_{\mathrm{parameters}}=n_{\mathrm{in}}n_{\mathrm{out}}+n_{\mathrm{out}}.

For the 784 → 128 → 64 → 10 architecture:

Layer Weights and biases Parameters
784→128784\to128 784(128)+128784(128)+128 100,480
128→64128\to64 128(64)+64128(64)+64 8,256
64→1064\to10 64(10)+1064(10)+10 650
Total 109,386

An activation value is computed for an observation; it is not a learned coefficient. The same weights are reused across every example and every batch.

Step by step Derive dense-layer shapes and parameter counts

1 · Count the coefficients of one output

For nn inputs, output jj uses zj=∑k=1nWjkxk+bjz_j=\sum_{k=1}^nW_{jk}x_k+b_j . It needs nn weights and one bias, hence n+1n+1 trainable scalars.

2 · Repeat for all outputs

With mm distinct outputs there are mm such rows:

P=m(n+1)=mn+m.P=m(n+1)=mn+m.

No additional parameter is introduced by evaluating an activation such as ReLU. Parametric activations are an exception and need their own count.

3 · Calculate the count for each layer

784⋅128=100352,100352+128=100480,784\cdot128=100352,\qquad100352+128=100480,
128⋅64=8192,8192+64=8256,128\cdot64=8192,\qquad8192+64=8256,
64⋅10=640,640+10=650.64\cdot10=640,\qquad640+10=650.

Adding the layer counts gives 100480+8256+650=109386100480+8256+650=109386 .

4 · Convert columns to a row-oriented batch

A single column computation is z=Wx+bz=Wx+b . Transposing it gives z⊤=x⊤W⊤+b⊤z^\top=x^\top W^\top+b^\top . Stack BB input rows into X∈ℝB×nX\in\mathbb R^{B\times n} :

Z=XW⊤+𝟏Bb⊤∈ℝB×m.Z=XW^\top+\mathbf1_Bb^\top\in\mathbb R^{B\times m}.

The ones vector 𝟏B\mathbf1_B repeats the same bias row BB times. It does not create BB learned biases.

5 · Separate storage from arithmetic

Each of BmBm output entries forms a length- nn dot product, so the leading arithmetic scales as O(Bmn)O(Bmn) . Parameter storage stays mn+mmn+m ; the batch activations use BmBm values. Changing batch size changes work and activation storage, not the model’s parameter count.

Why nonlinear composition matters

Remove the activations from two successive layers:

h=W1x+b1,y=W2h+b2.h=W_1x+b_1,\qquad y=W_2h+b_2.

Substitution gives

y=(W2W1)x+(W2b1+b2).y=(W_2W_1)x+(W_2b_1+b_2).

This is still affine. Adding further affine layers repeats the same collapse. With nonlinearities between layers, the next transformation instead operates on a nonlinear representation of the inputs. This is the basic mechanism behind hierarchical representation learning.

A transformation with a bias is affine; it is linear when the bias is zero. The distinction does not change the composition argument: any stack of affine layers without nonlinear activations is still one affine map.

Step by step Expand a stack of affine layers

Setting. x∈ℝd0x\in\mathbb R^{d_0} , W1∈ℝd1×d0W_1\in\mathbb R^{d_1\times d_0} , W2∈ℝd2×d1W_2\in\mathbb R^{d_2\times d_1} . Bias vectors have the matching output widths. There are no nonlinearities between the layers.

1 · Write the first layer coordinate by coordinate

hj=∑k=1d0(W1)jkxk+(b1)j.h_j=\sum_{k=1}^{d_0}(W_1)_{jk}x_k+(b_1)_j.

The second layer gives yi=∑j(W2)ijhj+(b2)iy_i=\sum_j(W_2)_{ij}h_j+(b_2)_i .

2 · Substitute the first expression

yi=∑j(W2)ij[∑k(W1)jkxk+(b1)j]+(b2)i.y_i=\sum_j(W_2)_{ij}\left[\sum_k(W_1)_{jk}x_k+(b_1)_j\right]+(b_2)_i.

Distribute multiplication across addition:

yi=∑j∑k(W2)ij(W1)jkxk+∑j(W2)ij(b1)j+(b2)i.y_i=\sum_j\sum_k(W_2)_{ij}(W_1)_{jk}x_k+\sum_j(W_2)_{ij}(b_1)_j+(b_2)_i.

3 · Regroup the finite sums

yi=∑k[∑j(W2)ij(W1)jk]xk+(W2b1)i+(b2)i.y_i=\sum_k\left[\sum_j(W_2)_{ij}(W_1)_{jk}\right]x_k+(W_2b_1)_i+(b_2)_i.

The bracket is exactly the (i,k)(i,k) entry of matrix product W2W1W_2W_1 . Therefore

y=W*x+b*,W*=W2W1,b*=W2b1+b2.y=W_*x+b_*,\qquad W_*=W_2W_1,\quad b_*=W_2b_1+b_2.

4 · Add a third layer

For v=W3y+b3v=W_3y+b_3 , substitution gives

v=(W3W2W1)x+W3W2b1+W3b2+b3.v=(W_3W_2W_1)x+W_3W_2b_1+W_3b_2+b_3.

Every additional affine layer repeats this step. For LL layers, the effective weight is WL⋯W1W_L\cdots W_1 , and each bias is multiplied by all later weights before being added.

5 · State what the conclusion does and does not say

The function remains affine, but a narrow intermediate layer can restrict its rank: rank(W2W1)≤d1\operatorname{rank}(W_2W_1)\le d_1 . A deep linear parameterization may also optimize differently from one effective matrix. Inserting ReLU makes its active diagonal mask depend on xx , so there is generally no single global W*,b*W_*,b_* covering every input.

Depth and width solve different representational problems

Width increases the number of features represented within a layer. Depth increases the number of successive transformations. In image models, the progression from pixels to edges, shapes, and higher-level features illustrates this composition. It does not imply that every hidden unit has a recognizable semantic role.

Neither dimension should be optimized in isolation. More capacity can introduce overfitting, difficult gradients, additional sensitivity to initialization, and greater computation. A deeper model failing where a shallower one succeeds can reflect optimization or implementation problems rather than insufficient expressive power.

Check tensor dimensions, parameter counts, and training behavior together. A larger representation is useful only when the optimization procedure can learn it reliably.

Check your understanding Why do ten linear layers not automatically create a nonlinear model?

A composition of affine maps is another affine map: W₂(W₁x+b₁)+b₂=(W₂W₁)x+(W₂b₁+b₂). Nonlinear activations are what prevent this collapse. The factorized parameterization can change optimization, but not the overall affine function class.
