Notation and references

The four reference PDFs are included unchanged. Page references count positions in each PDF, including its cover and contents. Figure credits identify the original page. Library-specific conventions are stated alongside the relevant equations.

The reinforcement-learning chapter draws on the primary papers and official resources listed below. Detailed calculation panels develop the equations in the chapters; their assumptions define where each result applies.

Official practical material

A tutorial or example script contains implemented operations or a training application. An API reference establishes the exact behavior of a component; it is not presented as an end-to-end experiment. PyTorch Geometric and Ignite are separate ecosystem packages. The classical coefficient-path, bias–variance and stacking examples come from scikit-learn rather than being forced into PyTorch.

These are selected links, not downloaded copies of the documentation. They require an internet connection. Linked tutorials may require data downloads and their own dependencies. Documentation and repositories can evolve; API-specific references in this edition point to PyTorch 2.13 documentation.

Python examples

Four downloadable scripts cover a complete forward and backward pass, regularization identities, a two-dimensional Conjugate Gradient calculation, and synthetic denoising. Each includes the inputs and numerical checks needed for that example.

The recorded example runs used PyTorch 2.10.0 on CPU. External training tutorials have their own dependencies and were not all executed as part of those checks. Synthetic examples illustrate a calculation; they do not establish performance on other datasets.

Using the examples

Python scripts run outside the browser. The equations, figures, and interactive calculations are displayed locally; external documentation links require internet access.
