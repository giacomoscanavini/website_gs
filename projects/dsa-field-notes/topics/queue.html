First in, first out

Use collections.deque. queue.append(x) adds at the back; queue.popleft() removes from the front. Both end operations are O(1). A list's pop(0) shifts all later elements and costs O(n).

Pattern What is queued Main rule
Work in arrival order Tasks or events Append at the back, remove from the front
Breadth-first search Discovered, unprocessed vertices Mark discovered when enqueuing
Level-by-level traversal Nodes in the current frontier Process the queue length captured at the level's start
Monotonic deque Candidate indices for a window extremum Expire from the front, remove dominated values from the back

Advantage: FIFO order gives fair arrival-order processing and breadth-first traversal. Limitations: a wide frontier can consume substantial memory; a FIFO queue does not prioritize a cheaper path in a weighted graph. Access near the middle of a deque is linear.

Breadth-first distances

Start with the source at distance zero. Remove one vertex, discover its unseen neighbors at distance distance[node] + 1, and enqueue them. With unweighted edges, every layer is one edge farther from the start.

Python
from collections import deque

# Expected time O(V + E): reachable vertices and their adjacency entries
# Extra space O(V): the queue and distance table
def bfs_distances(graph: dict[int, list[int]], start: int) -> dict[int, int]:
    queue = deque([start])
    distance = {start: 0}
    while queue:
        node = queue.popleft()
        for neighbor in graph.get(node, []):
            if neighbor not in distance:
                distance[neighbor] = distance[node] + 1
                queue.append(neighbor)
    return distance

Mark a vertex when enqueuing, not when removing it: otherwise two parents may enqueue the same vertex. V and E here refer to the reachable vertices and adjacency entries examined. Unreachable vertices do not appear in the result. A missing adjacency list means that vertex has no outgoing edges.

Monotonic deque: a maximum in each window

Keep candidate indices in increasing index order and decreasing value order. The front is the maximum candidate.

  1. Remove front indices that have left the window.
  2. Remove back indices whose values are no larger than the new value. The new value is at least as useful and expires later.
  3. Append the new index. Read the front once a complete window exists.
Python
from collections import deque

# Time O(n): every index enters and leaves the deque at most once
# Extra space O(k) working memory plus O(n - k + 1) output
def window_max(nums: list[int], k: int) -> list[int]:
    if not 1 <= k <= len(nums):
        raise ValueError("k must be between 1 and len(nums)")
    queue = deque()
    answer = []
    for right, value in enumerate(nums):
        while queue and queue[0] <= right - k:
            queue.popleft()
        while queue and nums[queue[-1]] <= value:
            queue.pop()
        queue.append(right)
        if right >= k - 1:
            answer.append(nums[queue[0]])
    return answer

Both ends are necessary: a stack alone cannot efficiently remove expired indices from the oldest end. Every index is inserted once and removed at most once, so total deque work is O(n).
