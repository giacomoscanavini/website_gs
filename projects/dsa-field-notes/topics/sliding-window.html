Sliding window

Maintain information about a contiguous range while its boundaries move forward.

In this topic
Common patternsFixed size: add one, remove oneLongest valid window: remove the violationShortest valid window: keep shrinking

Common patterns

A window is a contiguous part of a sequence. In these examples, left and right are included, so its length is right - left + 1.

Task What to maintain When to update the answer
Fixed-size sum or average A running total After the window reaches size k
Longest valid range Counts, a set, or another validity condition After shrinking away any violation
Shortest range meeting a threshold A running total While valid, before removing the leftmost item
Fixed-size maximum or minimum A deque of useful candidate indices Once the window is complete

Advantage: reuse the old window instead of recomputing its contents. Limitation: a variable window needs a condition that supports safe, one-directional boundary movement. It is not a general solution for every subarray problem.

Fixed size: add one, remove one

Build the first total. Each following move adds nums[right] and subtracts nums[right - k]. The outgoing index is right - k, not the new left boundary right - k + 1.

Python
# Time O(n): add and subtract each element at most once
# Extra space O(1)
def max_window_sum(nums: list[int], k: int) -> int:
    if not 1 <= k <= len(nums):
        raise ValueError("k must be between 1 and len(nums)")
    total = 0
    for i in range(k):
        total += nums[i]
    best = total
    for right in range(k, len(nums)):
        total += nums[right] - nums[right - k]
        best = max(best, total)
    return best

Negative values are fine here: the size is fixed. Initializing best from the first real window also handles an array whose window sums are all negative.

Longest valid window: remove the violation

Keep a set of characters in the current window. Before adding a character already in the set, remove characters from the left until its previous occurrence is gone. Then add the new character and measure the window.

Python
# Expected time O(n): each character enters and leaves once
# Extra space O(min(n, u)): u is the number of possible characters
def longest_unique(text: str) -> int:
    seen = set()
    left = 0
    best = 0
    for right, char in enumerate(text):
        while char in seen:
            seen.remove(text[left])
            left += 1
        seen.add(char)
        best = max(best, right - left + 1)
    return best

Use while, not if: removing one character may not remove the duplicate. The nested loop is still expected O(n) because each character enters and leaves the set at most once; left never resets.

Shortest valid window: keep shrinking

For nonnegative numbers and a positive target, extending a window cannot reduce its sum. Once the sum reaches the target, record its length and remove leftmost values while the condition remains true.

Python
# Time O(n): the two boundaries only move forward
# Extra space O(1)
def shortest_sum_at_least(nums: list[int], target: int) -> int:
    if target <= 0 or any(value < 0 for value in nums):
        raise ValueError("Use a positive target and nonnegative values")
    left = 0
    total = 0
    best = len(nums) + 1
    for right, value in enumerate(nums):
        total += value
        while total >= target:
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best > len(nums) else best

Why the restriction matters: with [1, -1, 5] and target 5, this rule records length 3, then removing 1 lowers the sum to 4 and stops shrinking. It misses the one-element range [5]. Negative numbers break this sum-based rule, not the fixed-window method above.

Reading the complexity comments

n is the input length unless another size is defined. Extra space excludes the input and counts stored results when they are constructed. Recursion frames count as extra space. Costs assume bounded-size values and constant-time comparisons; dictionary and set costs are expected under ordinary hashing.
