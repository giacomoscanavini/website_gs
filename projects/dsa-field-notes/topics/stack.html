Last in, first out

Use a Python list. stack.append(x) pushes; stack.pop() removes the top; stack[-1] reads it. Check if stack before reading or removing from an empty stack. Pushing and popping at the end are amortized O(1).

Pattern What the stack stores What removes an item
Nested brackets or expressions Unmatched opening symbols or partial values A matching close or completed expression
Undo Previous actions or states An undo request
Depth-first traversal Nodes still to explore Visiting the latest pending node
Monotonic stack Unresolved indices in value order A new value that resolves or dominates the top

Advantage: direct support for nesting and reversing the order of unfinished work. Limitation: only the top is immediately accessible; searching inside is linear, and the pending stack can grow to O(n).

Match nested brackets

An opening bracket is pushed. A closing bracket must match the most recent opening bracket. A closing bracket with an empty stack, a mismatch, or a nonempty final stack makes the string invalid.

Python
# Time O(n): each bracket is pushed or popped at most once
# Extra space O(n): unmatched opening brackets
def balanced(text: str) -> bool:
    opening = {"(", "[", "{"}
    matching = {")": "(", "]": "[", "}": "{"}
    stack = []
    for char in text:
        if char in opening:
            stack.append(char)
        elif char in matching:
            if not stack or stack.pop() != matching[char]:
                return False
        else:
            raise ValueError("Only brackets are accepted")
    return not stack

The empty string is balanced. This function accepts bracket characters only; it rejects other characters rather than silently interpreting them as brackets.

Monotonic stack: next greater value

Scan left to right. The stack stores indices whose next greater value is unknown. Its values are non-increasing from bottom to top. A new larger value resolves smaller values at the top; pop and record their answers before pushing the new index.

Python
# Time O(n): each index is pushed once and popped at most once
# Extra space O(n): stack and output
def next_greater(nums: list[int]) -> list[int | None]:
    answer = [None] * len(nums)
    stack = []
    for i, value in enumerate(nums):
        while stack and nums[stack[-1]] < value:
            j = stack.pop()
            answer[j] = value
        stack.append(i)
    return answer

Each popped index is finished permanently, so total pushes plus pops are linear. The comparison is < because the answer must be strictly greater. Equal values remain pending. Indices allow writing the answer back to the correct position; use i - j instead when the task asks for a distance.
